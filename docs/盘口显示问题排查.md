# 🔍 盘口显示问题排查指南

## 🐛 问题现象

```
[16:29:53] 🔄 自动加载比赛列表...
[16:29:53] 正在获取场次列表……
[16:29:54] 共获取到 0 场比赛（已过滤：0/66场有盘口）。
```

**说明**：

- 原始有 **66 场** 比赛
- 盘口匹配后 **0 场** 有盘口
- 因为勾选了"仅显示有盘口的比赛"，所以显示 **0 场**

## 🎯 原因分析

### 原因 1：勾选了"仅显示有盘口"但盘口匹配失败

**现象**：

- ✅ 必发网返回了 66 场比赛
- ✅ 500.com 返回了盘口数据（比如 30 场）
- ❌ 但队名或时间不匹配，导致 0 场匹配成功
- ⚠️ 因为勾选了过滤，所以显示 0 场

**可能的匹配失败原因**：

1. **队名不一致**：必发网和 500.com 的队名可能不完全相同
   - 必发网：`PSM马卡萨`
   - 500.com：`PSM马卡沙`（少一个字）
2. **日期格式问题**：日期提取错误

3. **小联赛比赛**：500.com 可能没有某些小联赛的盘口

### 原因 2：500.com 未返回盘口数据

**现象**：

- 500.com 没有该日期的盘口数据
- 可能是未来比赛或小联赛比赛

## ✅ 解决方案

### 方案 1：取消勾选"仅显示有盘口的比赛"（推荐）

**操作步骤**：

1. 取消勾选 ☑️ "仅显示有盘口的比赛（默认）"
2. 点击"刷新列表"

**效果**：

```
共获取到 66 场比赛，其中 30 场有盘口数据

比赛列表：
├─ PSM马卡萨 vs PSB宾唐伦佩阳  ✓ 盘口：球半
├─ 某小联赛比赛               盘口：需采集后匹配
├─ 阿雷佐德扎 vs 瓦尔不鲁韦   ✓ 盘口：0-1
└─ ...
```

### 方案 2：检查调试日志

**查看终端日志**：

```
📅 处理 2025-11-21 的比赛...
✅ 500.com找到 30 场有盘口的比赛
🔍 盘口样例: PSM马卡沙 vs PSB宾唐伦佩阳
🔍 比赛样例: PSM马卡萨 vs PSB宾唐伦佩阳
✅ 2025-11-21: 匹配到 15/20 场有盘口的比赛（过滤模式）
```

**根据日志判断**：

1. 如果显示"未获取到盘口数据" → 500.com 没有该日期盘口
2. 如果显示"匹配到 0/20 场" → 队名不匹配
3. 如果显示"匹配到 15/20 场" → 部分匹配成功

## 📊 盘口匹配逻辑

### 匹配流程

```
1. 按日期分组比赛
    ↓
2. 获取当天的500.com盘口数据
    ↓
3. 对每场比赛进行匹配：
    ├─ 精确匹配（队名+时间完全相同）
    ├─ 模糊匹配（队名相似度≥70%）
    └─ 匹配失败
    ↓
4. 根据过滤选项决定：
    ├─ 勾选过滤：只添加有盘口的比赛
    └─ 不勾选：添加所有比赛（有盘口的显示盘口）
```

### 匹配示例

**成功匹配**：

```
必发网: PSM马卡萨 vs PSB宾唐伦佩阳 16:30
500.com: PSM马卡萨 vs PSB宾唐伦佩阳 16:30
→ 精确匹配 ✅
```

**模糊匹配**：

```
必发网: PSM马卡萨 vs PSB宾唐伦佩阳
500.com: PSM马卡沙 vs PSB宾唐伦佩扬
→ 相似度 85% ✅
```

**匹配失败**：

```
必发网: 某小联赛球队A vs 球队B
500.com: （没有该比赛）
→ 无匹配 ❌
```

## 🎨 使用建议

### 推荐设置

**日常使用**：

- ☑️ **勾选** "仅显示有盘口的比赛"
- 优点：只看有价值的比赛
- 缺点：可能漏掉一些比赛

**查看所有比赛**：

- ☐ **不勾选** "仅显示有盘口的比赛"
- 优点：看到所有比赛
- 缺点：包含很多小联赛比赛

### 查询未来比赛

**设置未来天数**：

```
查询未来 [下拉选择] ▼
  ├─ 0天（不查未来）
  ├─ 1天（今天+明天）  ← 推荐
  ├─ 3天（今天+后3天）
  └─ 7天（今天+未来一周）
```

**未来比赛盘口**：

- 未开始的比赛：**可能有盘口**（开盘盘口）
- 进行中的比赛：**有盘口**（实时盘口）
- 已完场的比赛：**有盘口**（终盘盘口）

## 🐛 常见问题

### Q1: 为什么显示 0 场比赛？

**原因**：勾选了过滤，但所有比赛都没有盘口数据

**解决**：取消勾选"仅显示有盘口的比赛"

### Q2: 为什么有些比赛没有盘口？

**原因**：

1. 500.com 没有该比赛的盘口
2. 小联赛或冷门比赛
3. 未来比赛还未开盘

**正常行为**：这些比赛会显示"盘口：需采集后匹配"

### Q3: 盘口数据多久更新一次？

**更新机制**：

- 第一次获取：从 500.com 实时获取
- 后续 60 秒内：使用缓存
- 60 秒后：重新获取

**手动刷新**：点击"刷新列表"按钮

### Q4: 如何确认盘口数据是否正确？

**查看方法**：

1. 鼠标悬停在盘口上，会显示详细信息
2. 查看终端日志中的"示例盘口"
3. 与 500.com 网站对比
