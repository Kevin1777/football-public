## 🎯 核心改进

### 1. 推荐输出改变

**原来**：

```
🎯 最终下注建议：主队胜
```

**现在**：

```
🎯 最终下注建议：
✅ 推荐：主队让球 -0.5
盘口：受半球 (-0.5)
置信度：85%
理由：评分优秀，置信度85%
```

### 2. 让球盘口数值转换

**自动转换**：

- "球半" → 1.5
- "受平/半" → -0.25
- "平手" → 0.0

**方向判断**：

- 正数 = 主队让球（主队强）
- 负数 = 主队受让（客队强）

### 3. 数据集成

**自动获取**：

1. 必发交易明细（UG-PDF）
2. 500 彩票网让球盘口
3. 比赛元数据

**完整性检查**：

- 三项数据齐全才生成推荐
- 缺失则触发熔断（F-GATE）

## 🔧 技术细节

### 数据流程

```
1. 获取比赛列表（/api/bifaw/matches）
   ↓
2. 获取交易明细（/api/bifaw/match_detail）
   ↓
3. 获取让球盘口（/api/handicap/match）
   ↓
4. 生成推荐（/api/recommendation/generate）
   ↓
5. 格式化输出（VIS-E01 / Telegram）
```

### 评分逻辑

```python
# 1. 采集状态检查
if not (ug_pdf and handicap and metadata):
    return F-GATE熔断

# 2. 资金等级判定
level = determine_funding_level(trade_data)  # L1-L5

# 3. 成交指数计算
index = calculate_trade_index(trade_data)  # 主/和/客

# 4. FLM评分
flm = flm_scoring(trade_data, index)  # 热度前线

# 5. SPM评分
spm = spm_scoring(trade_data, handicap)  # 承压评分

# 6. DPI评分
dpi = dpi_scoring(flm, spm, trade_data)  # 风险整合

# 7. 风控检测
risk = run_risk_checks(...)  # SmartSafe/SS-Dagger/LVC/TPI

# 8. SBRE反解（如触发）
sbre = sbre_mechanism(level, index, dpi, risk)

# 9. 让球盘口落点推演
prediction = handicap_prediction(handicap, ..., sbre)

# 10. 最终推荐
final = generate_final_recommendation(prediction, sbre, dpi, risk)
```
