# 盘口数值自动转换说明

## ✅ 已实现功能

**系统已经实现了文字盘口 → 数值盘口的全自动转换！**

所有 API 返回的数据中，**每个盘口都同时包含两种形式**：

- `handicap_str` - 文字形式（如"球半"、"受平/半"）
- `handicap` - 数值形式（如 1.5、-0.25）

## 📊 返回数据格式

### 完整示例

```json
{
  "success": true,
  "data": {
    "home_team": "曼联",
    "away_team": "利物浦",

    // 初盘 - 同时包含文字和数值
    "initial_handicap_str": "受半球",  ← 文字形式
    "initial_handicap": -0.5,          ← 数值形式（自动转换）
    "initial_home_odds": 0.95,
    "initial_away_odds": 0.85,

    // 即时盘 - 同时包含文字和数值
    "current_handicap_str": "受平/半",  ← 文字形式
    "current_handicap": -0.25,          ← 数值形式（自动转换）
    "current_home_odds": 0.90,
    "current_away_odds": 0.90,

    // 历史数据 - 每条都包含文字和数值
    "history": [
      {
        "time": "2025-11-18 08:00:00",
        "handicap_str": "受半球",  ← 文字形式
        "handicap": -0.5,          ← 数值形式（自动转换）
        "home_odds": 0.95,
        "away_odds": 0.85
      }
    ]
  }
}
```

## 🎯 使用方法

### 方法 1: 只使用数值

```python
import requests

response = requests.post(
    "http://127.0.0.1:5001/api/handicap/match",
    json={"home_team": "曼联", "away_team": "利物浦"}
)

data = response.json()["data"]

# 直接使用数值
print(f"即时盘数值: {data['current_handicap']}")  # 输出: -0.25

# 分析盘口
if data['current_handicap'] > 0:
    print(f"主队让客队 {data['current_handicap']} 球")
elif data['current_handicap'] < 0:
    print(f"客队让主队 {abs(data['current_handicap'])} 球")
```

### 方法 2: 同时使用数值和文字

```python
# 同时获取两种形式
print(f"盘口: {data['current_handicap_str']} ({data['current_handicap']})")
# 输出: 盘口: 受平/半 (-0.25)
```

### 方法 3: 批量处理（只关注数值）

```python
response = requests.post(
    "http://127.0.0.1:5001/api/handicap/batch",
    json={
        "matches": [
            {"home_team": "曼联", "away_team": "利物浦"},
            {"home_team": "切尔西", "away_team": "阿森纳"}
        ]
    }
)

results = response.json()["results"]

# 提取所有数值
for r in results:
    data = r["data"]
    print(f"{data['home_team']} vs {data['away_team']}: {data['current_handicap']}")
# 输出示例:
# 曼联 vs 利物浦: -0.25
# 切尔西 vs 阿森纳: 0.5
```

## 📋 数值对照表

| 文字盘口 | 数值  | 说明             |
| -------- | ----- | ---------------- |
| 球半     | 1.5   | 主队让 1.5 球    |
| 平/半    | 0.25  | 主队让 0.25 球   |
| 平手     | 0.0   | 不让球           |
| 受平/半  | -0.25 | 主队受让 0.25 球 |
| 受半球   | -0.5  | 主队受让 0.5 球  |
| 受球半   | -1.5  | 主队受让 1.5 球  |

**规则**：

- **正数** = 主队让客队球（主队强）
- **负数** = 主队受让（客队强）
- **零** = 平手盘

## 🔍 数据字段说明

### 初盘数据

- `initial_handicap_str` - 初盘文字（如"球半"）
- `initial_handicap` - 初盘数值（如 1.5）
- `initial_home_odds` - 初盘主队水位
- `initial_away_odds` - 初盘客队水位
- `initial_time` - 初盘时间

### 即时盘数据

- `current_handicap_str` - 即时盘文字（如"受平/半"）
- `current_handicap` - 即时盘数值（如-0.25）
- `current_home_odds` - 即时盘主队水位
- `current_away_odds` - 即时盘客队水位
- `current_time` - 即时盘时间

### 历史数据

- `history[]` - 盘口变化历史数组
  - `time` - 时间
  - `handicap_str` - 文字盘口
  - `handicap` - 数值盘口
  - `home_odds` - 主队水位
  - `away_odds` - 客队水位

## 💡 实用技巧

### 1. 盘口变化分析（使用数值）

```python
initial = data['initial_handicap']  # 初盘数值
current = data['current_handicap']  # 即时盘数值
change = current - initial

if change > 0:
    print(f"盘口上升 {change:.2f} 球")
elif change < 0:
    print(f"盘口下降 {abs(change):.2f} 球")
else:
    print("盘口未变化")
```

### 2. 批量数据分析

```python
# 获取多场比赛，按盘口数值排序
matches_handicaps = []
for r in results:
    data = r["data"]
    matches_handicaps.append({
        'match': f"{data['home_team']} vs {data['away_team']}",
        'handicap': data['current_handicap']
    })

# 按盘口数值排序（从大到小）
sorted_matches = sorted(matches_handicaps, key=lambda x: x['handicap'], reverse=True)

for m in sorted_matches:
    print(f"{m['match']}: {m['handicap']}")
```

### 3. 筛选特定盘口

```python
# 筛选主队让球的比赛（正数）
home_advantage = [r for r in results if r['data']['current_handicap'] > 0]

# 筛选平手盘或接近平手的比赛
close_matches = [r for r in results if abs(r['data']['current_handicap']) <= 0.25]

# 筛选大盘口比赛（让球超过1球）
big_handicaps = [r for r in results if abs(r['data']['current_handicap']) > 1.0]
```

## ⚙️ 技术实现

转换在 `lottery500_client.py` 的 `_parse_handicap_response()` 方法中自动完成：

```python
# 解析盘口数值（自动调用）
if result['initial_handicap_str']:
    result['initial_handicap'] = self.parse_handicap(result['initial_handicap_str'])
if result['current_handicap_str']:
    result['current_handicap'] = self.parse_handicap(result['current_handicap_str'])
```

**无需任何额外操作，所有文字盘口都会自动转换为数值！**
