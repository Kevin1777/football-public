## 现在请按以下步骤操作

### 步骤 1：确保已登录

1. 访问采集控制台：http://127.0.0.1:5001/collect
2. 查看"登录状态"卡片，如果显示"当前未登录"，请：
   - 点击"获取验证码"
   - 输入验证码
   - 点击"提交验证码"
   - 等待提示"登录成功"

### 步骤 2：尝试抓取明细

1. 点击"获取场次"按钮
2. 等待场次列表加载
3. 选择任意一场比赛，点击"抓取明细"按钮
4. **观察服务器终端的日志输出**

### 步骤 4：分析调试文件

#### 查看 PNG 截图

1. 双击打开 `.png` 文件
2. 检查页面显示的内容：
   - ✅ 如果看到比赛数据表格 → 登录成功
   - ❌ 如果看到登录表单 → cookies 已过期
   - ❌ 如果看到空白页 → 页面未加载
   - ❌ 如果看到错误信息 → 记录错误内容

#### 查看 HTML 文件

1. 用文本编辑器或浏览器打开 `.html` 文件
2. 搜索关键内容：
   - 搜索 "登录" - 如果找到很多，说明需要重新登录
   - 搜索 "买家挂牌" - 如果找到，说明明细页面已加载
   - 搜索 "必发指数" - 如果找到，说明在站内
   - 搜索 "错误" - 查看是否有错误信息

### 步骤 5：常见问题解决

#### 问题 1：登录状态验证失败

**症状：**

- 错误信息：`明细页面登录状态验证失败`
- debug_html 中只有 `detail_login_timeout` 文件

**解决方法：**

1. 检查 `detail_login_check_*.html` 文件内容
2. 如果包含登录表单，需要在采集控制台重新登录
3. 如果看到站内内容但仍然失败，可能是检测逻辑太严格

**临时解决方案：**
删除 `cookies.json` 文件，重新登录：

```powershell
cd d:\MSM\Cursor\football
del cookies.json
# 然后访问 http://127.0.0.1:5001/collect 重新登录
```

#### 问题 2：页面打开但没有内容

**症状：**

- 有 `detail_page_opened` 截图，但是空白
- HTML 文件很小

**解决方法：**
页面可能需要更长的加载时间，或者明细链接不正确。

#### 问题 3：找不到关键字

**症状：**

- 有 `detail_page_loaded` 截图
- 错误信息：`未找到关键字「买家挂牌、卖家挂牌」`

**解决方法：**

1. 检查 `detail_page_loaded_*.html` 文件
2. 搜索是否有比赛数据
3. 如果有数据但格式不同，可能需要调整解析器

#### 问题 4：Chrome/ChromeDriver 相关错误

**症状：**

- 错误信息包含 "chromedriver" 或 "Chrome binary"

**解决方法：**
确保已安装 Chrome 和 ChromeDriver，版本需要匹配。

## 快速测试脚本

如果想快速测试登录状态，可以运行：

```python
# test_login.py
from services import BifawClient

client = BifawClient()

# 测试 cookies 是否有效
try:
    status = client.get_cookie_status()
    print("Cookie 状态：", status)

    # 尝试访问主页
    html = client.fetch_page_html("/bifaw/index.php")

    if "登录" in html and "验证码" in html:
        print("❌ Cookies 已过期，需要重新登录")
    elif "必发指数" in html or "标盘" in html:
        print("✅ Cookies 有效，登录状态正常")
    else:
        print("⚠️ 无法确定登录状态")
        with open("login_test.html", "w", encoding="utf-8") as f:
            f.write(html)
        print("页面内容已保存到 login_test.html")

except Exception as e:
    print("❌ 测试失败：", e)
```

保存为 `test_login.py` 并运行：

```powershell
python test_login.py
```
