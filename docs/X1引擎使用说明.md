# X1 全侦破版引擎使用说明

## 概述

X1 全侦破版引擎基于专业盘口分析理论，实现：

- ✅ 成交明细 PDF 三段式侦破（早/中/晚）
- ✅ 五级资金分层系统
- ✅ FLM/SPM/DPI 三大评分模块
- ✅ 四大风控机制
- ✅ SBRE 反解机制

## 启用方法

### 方法 1：修改 app.py

```python
# 在 app.py 中
USE_ENGINE_X1 = True  # 改为True

if USE_ENGINE_X1:
    from recommendation.handicap_engine_x1_fulltrace import HandicapEngineX1FullTrace
    handicap_engine = HandicapEngineX1FullTrace()
else:
    handicap_engine = HandicapRecommendationEngineV2()
```

### 方法 2：环境变量

```bash
export HANDICAP_ENGINE=X1
python app.py
```

## 核心模块

### 1. 三段式 PDF 分析

**早期（0-30%）** - 虚挂识别

- 净流判断
- 虚假热度识别

**中期（30-70%）** - 吸筹判断

- 动量计算
- 方向确认

**尾盘（70-100%）** - 兑现/冲洗

- 爆量检测
- 执行确认

### 2. 五级资金系统

| 等级 | 资金范围  | 响应权重 | 策略         |
| ---- | --------- | -------- | ------------ |
| L1   | <5 万     | 1.00     | 强制 SBRE    |
| L2   | 5-15 万   | 0.85     | 自动反打     |
| L3   | 15-70 万  | 0.65     | 热度+盈亏    |
| L4   | 70-150 万 | 0.35     | 评分失败介入 |
| L5   | >150 万   | 0.15     | 双重验证     |

### 3. 风控机制

**SmartSafe** - 结构支撑验证

- 检查盘口是否有热度支撑
- 成交量分布合理性

**SS-Dagger** - 诱导识别

- 反热放量
- 盘口异常

**LVC** - 落点验证

- 方向一致性
- 虚脱预警

**TPI** - 穿盘预警

- 极端成交
- 盘口不响应

## 集成示例

```python
from recommendation.handicap_engine_x1_fulltrace import HandicapEngineX1FullTrace

engine = HandicapEngineX1FullTrace()

result = engine.analyze(
    match_data={'home': '利物浦', 'away': '曼城'},
    trade_data=df_trades,  # 成交明细DataFrame
    handicap_data={'line': -0.5, 'odds': 1.95}
)

print(f"推荐: {result['recommendation']}")
print(f"置信度: {result['confidence']}")
```

## 注意事项

1. **数据要求**

   - 成交明细至少 180 秒完整数据
   - 主客对齐验证
   - 时间锚同步（Δt≤60s）

2. **熔断条件**

   - 任一主源缺失 →F-GATE
   - PDF 解析失败 →F-EVD
   - 指数占比混淆 →F-CONS

3. **最佳实践**
   - 使用完整成交明细
   - 确保盘口数据实时
   - 关注风控触发
