# 数据行被误当作表头修复

## 🐛 问题描述

从截图看，表格显示异常：

- ✅ 列名正确：`成交时间`、`价位`、`买家挂牌` 等
- ❌ 表头第二行显示数值：`14,020`、`1.73`、`9,599` 等
- ❌ 下面全是 `NaN`

**原因**：第一行数据被误认为是表头的第二级！

## 🔍 问题原因

### 原始逻辑（有问题）

`extract_section` 函数假设表头总是有**两行**：

```python
header_level1 = normalized_rows[header_index]      # 第1行：成交时间、价位...
header_level2 = normalized_rows[header_index + 1]  # 第2行：假设还是表头
column_names = build_column_names(header_level1, header_level2)
data_start_index = header_index + 2  # 从第3行开始才是数据
```

**实际情况**：

- 第 1 行：`成交时间`、`价位`、`买家挂牌` ... （表头） ✅
- 第 2 行：`14,020`、`1.73`、`9,599` ... （数据！） ❌ 被当作表头
- 第 3 行：`4,490`、`3.65`、`11,301` ... （数据）
- ...

结果：

- 第 2 行数据被合并到列名中
- 真实数据从第 3 行开始提取
- 导致表头显示错误，数据缺失第一行

## ✅ 修复方案

### 智能检测第二行

添加检测逻辑，判断第二行是**表头**还是**数据**：

```python
# 检查第二行是否真的是表头，还是数据行
if header_index + 1 < len(normalized_rows):
    header_level2 = slice_from_col(normalized_rows[header_index + 1])
    # 检查第二行是否包含时间格式（如果有，说明是数据行）
    second_row_text = " ".join(str(c) for c in header_level2 if c)
    is_data_row = bool(re.search(r"\d{2}-\d{2}\s+\d{2}:\d{2}", second_row_text))

    if is_data_row:
        # 第二行是数据行，不是表头！只使用一级表头
        column_names = [normalize_cell(c) or f"列{i+1}" for i, c in enumerate(header_level1)]
        data_start_index = header_index + 1  # 从第二行开始就是数据 ✅
    else:
        # 第二行是表头的第二级，使用两级表头
        column_names = build_column_names(header_level1, header_level2)
        data_start_index = header_index + 2  # 从第三行开始是数据
```

**检测方法**：

- 如果第二行包含时间格式（如`11-06 08:30`），说明是数据行
- 如果第二行不包含时间格式，说明是表头的第二级

### 修复无表头数据表格

当表格完全没有表头时（分离的表头和数据），使用预定义的标准列名：

```python
if has_time and len(normalized_rows) >= 5:
    # 这是一个纯数据表格（表头在别处）
    header_index = -1
    header_col = 0
    # 使用标准列名顺序（与必发指数网的标准表头一致）
    standard_columns = [
        "成交时间", "价位", "买家挂牌", "成交量", "比例",
        "赔付率", "必指", "赔指", "跑指", "凯指", "欧指", "前期"
    ]
    max_cols = max(len(row) for row in normalized_rows)
    if max_cols > len(standard_columns):
        column_names = standard_columns + [f"额外列{i}" for i in range(...)]
    else:
        column_names = standard_columns[:max_cols]
    data_start_index = 0  # 从第一行开始就是数据
```
