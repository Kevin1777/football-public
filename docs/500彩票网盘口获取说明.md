# 📊 500 彩票网盘口获取说明

## 🎯 问题现象

**现象**：明明 500.com 有盘口数据，但我们的系统获取不到

**原因**：URL 用错了

## 🐛 根本原因

### 之前的错误实现

```python
# ❌ 错误：只能查完场比赛
url = f"https://live.500.com/wanchang.php?e={formatted_date}"
```

**问题**：

- `wanchang.php` = **完场比分页面**
- 只显示已经完场的比赛
- 今天或未来的比赛不会出现在这个页面

### 正确的实现

```python
# ✅ 正确：根据日期选择页面
if match_date < today:
    # 过去的日期：使用完场页面
    url = f"https://live.500.com/wanchang.php?e={formatted_date}"
else:
    # 今天或未来：使用系统彩页面
    url = f"https://live.500.com/index.php?e={date_str}"
```

**逻辑**：

- 过去的日期 → 使用 `wanchang.php`（完场页面）
- 今天或未来 → 使用 `index.php`（系统彩页面）

## 📖 500 彩票网页面说明

### 1. 完场比分页面

**URL**: `https://live.500.com/wanchang.php?e=2025-11-20`

**特点**：

- 只显示已完场的比赛
- 有最终比分
- 有完整的盘口历史

**适用场景**：

- 查询历史比赛
- 分析完场数据
- 回测模型

### 2. 系统彩页面

**URL**: `https://live.500.com/index.php?e=20251121`

**特点**：

- 显示今天和未来的比赛
- 显示实时盘口
- 包括未开始、进行中、已完场的比赛

**适用场景**：

- 查询今天的比赛
- 查询未来比赛
- 实时盘口监控

### 3. 日期格式差异

| 页面         | 日期参数 | 格式       | 示例           |
| ------------ | -------- | ---------- | -------------- |
| wanchang.php | `e`      | YYYY-MM-DD | `e=2025-11-20` |
| index.php    | `e`      | YYYYMMDD   | `e=20251121`   |

## 🎯 使用建议

- 使用：`wanchang.php`（完场页面）
- 优点：数据完整，有最终比分

**查询今天比赛**：

- 日期：选择今天
- 使用：`index.php`（系统彩页面）
- 优点：实时盘口，包括未开始的比赛

**查询未来比赛**：

- 日期：选择未来日期
- 使用：`index.php`（系统彩页面）
- 优点：可以看到开盘盘口

### 自动选择逻辑

系统会自动根据日期选择合适的页面：

```python
today = datetime.now().strftime("%Y-%m-%d")

if match_date < today:
    # 自动使用完场页面
    page = "wanchang.php"
else:
    # 自动使用系统彩页面

```

## 🐛 故障排查

### Q1: 为什么今天的比赛获取不到盘口？

**检查**：

1. 查看日志，确认使用的 URL
2. 应该看到 `index.php?e=20251121`
3. 如果看到 `wanchang.php`，说明逻辑有问题

**解决**：确保代码已更新

### Q2: 为什么昨天的比赛获取不到？

**检查**：

1. 昨天的比赛是否已完场
2. 如果还在进行中，数据可能不完整

**解决**：等待比赛完场

### Q3: 如何验证获取的盘口数据正确？

**方法**：

1. 打开 500.com 网站
2. 手动查看盘口
3. 对比系统获取的数据
