# 元数据重复显示修复

## 🐛 问题描述

完场回查抓取明细后，页面顶部显示大量重复的元数据：

```
2025-11-06 08:10 · 阿根廷杯 · 萨蒙立(中) vs 阿根廷青年人
2025-11-06 08:10 · 阿根廷杯 · 萨蒙立(中) vs 阿根廷青年人
2025-11-06 08:10 · 阿根廷杯 · 萨蒙立(中) vs 阿根廷青年人
... (重复多次)
```

## 🔍 问题原因

在 `parser/html_parser.py` 的 `parse_bifa_html` 函数中：

```python
# 问题代码
for section in sections:
    # 每个section都添加一个metadata
    metadata.append({
        "source": "html",
        "title": section.get("title"),
        "subtitle": section.get("subtitle"),
        "title_meta": page_title_meta,
    })
    for row in section["rows"]:
        rows.append(dict(row))
```

**问题**：

- 页面可能有多个表格（比如主盘、副盘等），每个表格解析为一个 section
- 循环遍历 sections 时，每次都添加一个 metadata
- 导致 metadata 列表中有多个相同的元数据
- 前端遍历显示时，就会出现重复

## ✅ 修复方案

**修改位置**：`parser/html_parser.py` 第 337-355 行

```python
# 修复后的代码
rows: List[Dict[str, Optional[str]]] = []
metadata: List[Dict[str, Optional[str]]] = []
notes: List[str] = []

# 只添加一次metadata，使用页面级别的标题信息
first_section = sections[0] if sections else {}
metadata.append(
    {
        "source": "html",
        "title": first_section.get("title"),
        "subtitle": first_section.get("subtitle"),
        "title_meta": page_title_meta,  # 使用页面级别的标题信息（优先使用传入的match）
    }
)

# 遍历所有sections收集数据行，但不再重复添加metadata
for section in sections:
    for row in section["rows"]:
        rows.append(dict(row))
    notes.extend(section.get("notes", []))
```

**关键改动**：

1. ✅ 在循环**之前**添加一次 metadata
2. ✅ 使用第一个 section 的 title 和 subtitle
3. ✅ 使用统一的 page_title_meta（优先使用传入的 match 参数）
4. ✅ 循环中只收集数据行，不再添加 metadata

```

    ↓

    ↓
解析器：
  1. 使用match中的信息作为page_title_meta
  2. 解析多个表格（sections）
  3. 只添加一次metadata ✨ 修复点
  4. 遍历所有sections收集数据行
    ↓

    ↓

  - 元数据区域：显示1条信息 ✅
  - 数据表格：显示所有数据行
```

## 📝 为什么标盘场次正常？

标盘场次的明细页面通常只有一个主表格，所以 sections 列表只有 1 个元素，即使每个 section 都添加 metadata，也只会添加 1 次，因此看起来正常。

完场回查的明细页面可能包含多个表格（主盘、副盘、历史等），导致 sections 有多个元素，循环添加 metadata 就会重复。
