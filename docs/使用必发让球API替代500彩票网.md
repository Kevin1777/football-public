# 使用必发让球 API 替代 500 彩票网

## 🎯 问题回顾

**500 彩票网的问题：**

- ❌ 完场比赛历史数据过期
- ❌ 小联赛可能未收录
- ❌ 需要复杂的球队名称模糊匹配
- ❌ 数据可能不匹配

## ✅ 解决方案：使用必发指数网本身

### 为什么选择必发？

| 特性         | 必发指数网      | 500 彩票网      |
| ------------ | --------------- | --------------- |
| **完场数据** | ✅ 支持         | ❌ 历史过期     |
| **数据匹配** | ✅ 100%准确     | ⚠️ 需要模糊匹配 |
| **小联赛**   | ✅ 都有         | ❌ 可能缺失     |
| **登录状态** | ✅ 已登录       | ❌ 需要新连接   |
| **集成难度** | ✅ 极简单       | ⚠️ 复杂         |
| **同源数据** | ✅ 交易明细同源 | ❌ 跨站         |

## 📊 实施内容

### 1. 添加必发让球 API 方法

**文件：`services/bifaw_client.py`**

```python
def fetch_asian_handicap(
    self,
    match_id: str,
    market_id: str,
    home_sid: str,
    away_sid: str,
    opentime: str,
) -> Optional[Dict]:
    """
    从必发指数网获取让球盘口数据

    Args:
        match_id: 比赛ID (matchid/tmid)
        market_id: 市场ID (marketid)
        home_sid: 主队ID
        away_sid: 客队ID
        opentime: 开赛时间戳

    Returns:
        盘口数据字典，包含让球数、赔率等信息
    """
    url = "https://www.bifaw.com/bifaw/serveodds.php"
    params = {
        "matchid": match_id,
        "marketid": market_id,
        "home_sid": home_sid,
        "away_sid": away_sid,
        "opentime": opentime,
        "oddstype": "5",  # 5=让球盘（asian handicap）
        "action": "result",  # 完场数据
        "rows": "50",
    }

    response = self.session.get(url, params=params, timeout=15)
    data = response.json()

    return {
        "source": "bifaw",
        "raw_data": data,
        # TODO: 解析具体的让球数和赔率
    }
```
