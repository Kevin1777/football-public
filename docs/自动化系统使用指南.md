# ⚽ 足球比赛自动推荐系统

## 📖 系统简介

这是一个**完全自动化**的足球比赛推荐系统，具有以下功能：

### ✨ 核心功能

1. **🤖 全自动运行**

   - 自动登录（手动登录一次后自动保持）
   - 定时采集即将开始的比赛数据
   - 自动分析交易明细
   - 生成推荐并推送到 Telegram

2. **📊 数据采集**

   - 实时采集即将开始比赛的交易明细
   - 批量采集历史完场数据
   - 数据存储到 SQLite 数据库

3. **🎯 智能推荐**

   - 基于成交量分布分析
   - 赔率变化趋势分析
   - 买卖盘口差异分析
   - 综合置信度评估

4. **📱 Telegram 推送**
   - 自动推送推荐结果
   - 包含置信度和理由
   - 美观的消息格式

## 🚀 快速开始

### 1. 安装依赖

```bash
cd d:\MSM\Cursor\football
pip install -r requirements_automation.txt
```

### 2. 首次登录

访问采集控制台完成一次登录（保存 cookies）：

```bash

```

然后访问 `http://127.0.0.1:5001/collect`，按步骤完成验证码登录。

### 3. 配置 Telegram Bot

运行主程序并选择配置：

```bash

```

选择 `3. 配置Telegram Bot`，按提示操作：

#### 3.1 创建 Telegram Bot

1. 在 Telegram 搜索 `@BotFather`
2. 发送 `/newbot` 创建机器人
3. 设置名称和用户名
4. 获取 **Bot Token**

#### 3.2 获取 Chat ID

1. 在 Telegram 搜索 `@userinfobot`
2. 发送任意消息
3. 获取你的 **Chat ID**

#### 3.3 输入配置

将 Bot Token 和 Chat ID 输入程序，系统会自动测试连接。

### 4. 启动自动化系统

```bash
python main_automation.py
```

选择 `1. 启动自动化调度器`

## 📅 系统运行逻辑

### 自动任务调度

```
每小时运行一次
├─ 获取未来2天的比赛列表
├─ 筛选2小时内即将开始的比赛
├─ 对每场比赛：
│  ├─ 采集交易明细
│  ├─ 分析数据
│  ├─ 生成推荐
│  ├─ 如果置信度≥65%，推送到Telegram
│  └─ 保存到数据库
└─ 完成

每天凌晨3点
├─ 采集前一天的完场数据
├─ 用于训练和完善推荐算法
└─ 保存到数据库
```

### 推荐逻辑

```python
# 分析维度
1. 成交量分布 - 分析主胜/平局/客胜的交易量
2. 赔率变化 - 分析赔率上升/下降趋势
3. 盘口差异 - 分析买卖挂牌的差异

# 综合判断
- 三个维度都支持同一方向 → 高置信度
- 部分维度支持 → 中等置信度
- 信号冲突或不足 → 不推荐
```

## 🗄️ 数据库结构

SQLite 数据库 `match_data.db`：

### matches 表 - 比赛信息

- match_id（主键）
- league（联赛）
- kickoff（开球时间）
- home_team（主队）
- away_team（客队）
- score（比分）
- detail_url（明细链接）

### trade_data 表 - 交易数据

- match_id（外键）
- data_json（DataFrame 的 JSON 格式）
- collected_at（采集时间）

### analysis_results 表 - 分析结果

- match_id（外键）
- recommendation_direction（推荐方向）
- confidence（置信度）
- reason（推荐理由）
- analysis_json（完整分析 JSON）

### notifications 表 - 推送记录

- match_id（外键）
- sent_at（发送时间）
- success（是否成功）
- message（消息内容）

## 🔧 高级配置

### 调整置信度阈值

编辑 `recommendation/analyzer.py`：

```python
class MatchAnalyzer:
    def __init__(self):
        self.confidence_threshold = 0.65  # 改为你需要的值（0-1）
```

### 调整采集频率

编辑 `automation/scheduler.py`：

```python
# 每30分钟检查一次
schedule.every(30).minutes.do(self.collect_upcoming_matches)

# 改为每2小时检查一次
schedule.every(2).hours.do(self.collect_upcoming_matches)
```

### 调整提前采集时间

编辑 `automation/scheduler.py`：

```python
# 采集2小时内即将开始的比赛
upcoming = self._filter_upcoming_matches(matches, hours=2)

# 改为1小时
upcoming = self._filter_upcoming_matches(matches, hours=1)
```

## 🐛 故障排查

### Telegram 推送失败

1. 检查配置文件：`telegram_config.json`
2. 验证 Bot Token 和 Chat ID
3. 确保机器人已启用
4. 运行测试：选择菜单 `5. 测试Telegram推送`

### 采集失败

1. 检查登录状态：访问 `http://127.0.0.1:5001/collect`
2. 查看 `cookies.json` 是否存在
3. 重新登录获取新的 cookies

### 数据库错误

1. 检查 `match_data.db` 文件权限
2. 查看日志文件：`automation_main.log`
