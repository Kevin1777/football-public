## 🔍 当前调查中的问题

### 完场回查 URL 不正确 ⚠️

**用户反馈**：

> 完场回查不是和标盘指数的页面一样的吗，都是从标盘明细中来抓取数据

**问题分析**：

1. **标盘场次（即将开始）** ✅

   - URL: `matchDetails.php?id=xxx`
   - 数据: 详细的时间序列交易明细
   - 行数: 几十到上百行

2. **完场回查** ❌
   - 当前 URL: `sporttery.php?matchid=xxx&type=1&oddstype=1&subtype=8`
   - 当前数据: 只有盘口汇总（主/和/客统计）
   - 行数: 9 行

**发现的线索**：

从 `sporttery.php` 页面的 HTML 中找到：

```html
<li onclick="openMatchDetails('34954592','250506212',...)">标盘明细</li>
<li onclick="openMacth('34954592','250506212',...)">标盘交易历史/现有订单</li>
```

说明 sporttery.php 页面上有**链接**指向真正的标盘明细！

**测试中的解决方案**：

正在测试的 URL 格式：

1. `matchDetails.php?matchid={id}&fff=4`
2. `matchDetails.php?matchid={id}`
3. `matchDetails.php?id={id}`
4. `historysporttery.php?matchid={id}`
