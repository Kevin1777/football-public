# 异步数据采集使用指南

## 概述

异步批量采集脚本 (`batch_collect_details_async.py`) 可以大幅提升数据采集速度，相比原版单线程采集，速度提升 **5-10 倍**。

## 核心优化

1. **并发采集**：支持多任务并发（默认 10 个并发）
2. **智能跳过**：自动跳过已采集的比赛
3. **进度显示**：实时显示采集进度
4. **异步 IO**：充分利用等待时间

## 使用方法

### 基础用法

```bash
# 采集最近7天的200场比赛，使用10个并发
python scripts/batch_collect_details_async.py --rows 200 --days 7 --workers 10
```

### 参数说明

| 参数        | 说明                                 | 默认值  |
| ----------- | ------------------------------------ | ------- |
| `--rows`    | 采集比赛数量                         | 50      |
| `--days`    | 往前推 N 天（0=仅今天，1=今天+昨天） | 1       |
| `--workers` | 并发数（建议 5-15）                  | 10      |
| `--output`  | 输出目录                             | `data/` |

### 使用示例

#### 1. 快速采集最近 2 天的比赛

```bash
python scripts/batch_collect_details_async.py --rows 100 --days 2 --workers 12
```

#### 2. 大量采集完场回查数据（推荐用于扩展样本）

```bash
# 采集最近30天的500场比赛
python scripts/batch_collect_details_async.py --rows 500 --days 30 --workers 15
```

#### 3. 仅采集今天的比赛

```bash
python scripts/batch_collect_details_async.py --rows 50 --days 0 --workers 8
```

## 性能对比

| 版本              | 100 场比赛耗时 | 速度         |
| ----------------- | -------------- | ------------ |
| 原版（单线程）    | ~8 分钟        | ~12 场/分钟  |
| 异步版（10 并发） | ~1 分钟        | ~100 场/分钟 |

**速度提升：8 倍**

## 注意事项

### 1. 并发数设置

- ✅ **推荐并发数**：8-12
- ⚠️ **不建议过高**：>20 可能导致被封 IP
- 📊 **根据网络调整**：网络好可以提高到 15

### 2. 数据存储

采集的数据会按日期分目录存储：

```
data/
  ├── 2025/
  │   ├── 11/
  │   │   ├── 26/
  │   │   │   ├── 2025-11-26_英超_阿森纳_vs_曼联_2_1_1900.json
  │   │   │   └── ...
```

### 3. 自动跳过

脚本会自动检查已存在的文件，避免重复采集。

### 4. 日志记录

- **控制台输出**：实时显示采集进度
- **日志文件**：`batch_collect_async.log`

## 故障排查

### 问题 1：采集失败率高

**解决方案**：

- 降低并发数（--workers 5）
- 增加 days 参数，采集更早的比赛

### 问题 2：内存占用高

**解决方案**：

- 降低并发数
- 分批采集（每次--rows 100）

### 问题 3：部分比赛无数据

**原因**：必发网清空了完场比赛的明细数据

**解决方案**：

- 尽量采集当天或最近 2-3 天的比赛
- 完场回查时，选择 7 天内的比赛
