   - 显示回测结果和盈亏

### 3. JavaScript 功能

#### `showRecommendation()` - 推荐引擎

```javascript
输入：主队、客队、联赛、时间、明细URL
调用：POST /api/recommendation/generate
输出：VIS-E01格式推荐报告
```

#### `showBacktest()` - 回测分析

```javascript
输入：比赛信息 + 实际比分
调用：POST /api/backtest/single
输出：回测报告 + 盈亏结果
```

## 🚀 使用方法

### 访问主页

```
http://127.0.0.1:5001/
```

### 1. 数据采集流程

1. 点击"获取验证码" → 输入验证码登录
2. 登录成功后，点击"获取场次"查看比赛列表
3. 选择比赛，抓取交易明细

### 2. 生成推荐

1. 点击"🎯 打开推荐引擎"
2. 按提示输入比赛信息
3. 确认后生成推荐
4. 在日志区域查看 VIS-E01 报告

### 3. 执行回测

1. 点击"📈 开始回测"
2. 输入历史比赛信息和实际比分
3. 查看回测结果和盈亏

### 4. PDF 解析（旧功能）

1. 点击右上角"📄 PDF 解析"
2. 上传 PDF 文件
3. 下载 CSV 数据
