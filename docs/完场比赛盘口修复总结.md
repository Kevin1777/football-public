# 完场比赛盘口获取修复总结

## 🔍 问题发现

### 问题 1：球队名称没有清理

**日志显示：**

```
清理后: 墨西哥美洲 vs 莱昂  ← 应该是"美洲"，但没清理！
```

**原因：**
`_clean_team_name`函数只去除`[主]`、`[客]`等后缀，**没有去除国家前缀**。

### 问题 2：500 彩票网无数据

**返回内容：**

```
暂无该场比赛的数据
```

**原因：**

1. 500 彩票网可能不保存太久的历史数据
2. 某些小联赛（如墨西哥联赛）可能未被收录

## ✅ 已实施的修复

### 1. 修复`_clean_team_name`函数

**修复前：**

```python
def _clean_team_name(self, team_name: str) -> str:
    # 只去除 [主]、[客] 等后缀
    suffixes = ['[主]', '[客]', ...]
    for suffix in suffixes:
        team_name = team_name.replace(suffix, '')
    return team_name.strip()
```

**修复后：**

```python
def _clean_team_name(self, team_name: str) -> str:
    # 1. 去除后缀
    suffixes = ['[主]', '[客]', ...]
    for suffix in suffixes:
        team_name = team_name.replace(suffix, '')

    # 2. 去除国家/地区前缀（新增！）
    prefixes = [
        '墨西哥', '阿根廷', '巴西',
        '新墨西哥', '洛杉矶', ...
    ]
    for prefix in prefixes:
        if team_name.startswith(prefix):
            team_name = team_name[len(prefix):]
            logger.debug(f"去除前缀'{prefix}': {team_name}")
            break

    return team_name
```

**效果：**

```
"墨西哥美洲" → "美洲"
"新墨西哥联" → "联"
"阿根廷河床" → "河床"
```
