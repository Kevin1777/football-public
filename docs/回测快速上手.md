## 📋 完场回查操作步骤

### 1. 登录必发网站

确保 Cookie 有效

### 2. 进入完场回查

找到"完场回查"或"历史比赛"页面

### 3. 搜索比赛

输入球队名称或选择日期

### 4. 复制明细 URL

点击"查看明细"，复制浏览器地址栏的 URL

### 5. 记录比分

从比赛结果记录实际比分

## 💡 使用技巧

### 选择合适的比赛

1. **强弱分明的比赛**

   - 易于验证推荐准确性
   - 如：豪门 vs 中下游球队

2. **势均力敌的比赛**

   - 测试推荐引擎的区分能力
   - 如：强强对话

3. **冷门比赛**
   - 验证风控机制
   - 如：小球队爆冷

### 样本数量建议

- **初步测试**：5-10 场（验证功能）
- **基础评估**：20-30 场（初步统计）
- **深度分析**：50+场（准确评估）
- **完整训练**：100+场（模型优化）

### 结果分析

1. **记录每次回测**

   - 比赛信息
   - 推荐结果
   - 实际结果
   - 盈亏情况

2. **计算统计数据**

   - 总场次
   - 胜率
   - ROI
   - 最大连赢/连输

3. **分析失败案例**
   - 为什么推荐错误？
   - 哪类比赛容易失误？
   - 如何优化策略？

## 🎯 常见问题

### Q1：明细 URL 从哪里获取？

**A**：登录必发网站 → 完场回查 → 找到比赛 → 点击"查看明细" → 复制 URL

### Q2：推荐结果在哪里？

**A**：回测报告中的【推荐结果】部分

### Q3：如何判断推荐是否正确？

**A**：查看【验证结果】部分，显示 WIN/LOSE 等结果类型

### Q4：盈亏如何计算？

**A**：

- 全赢：+0.90
- 半赢：+0.45
- 走水：0.00
- 半输：-0.50
- 全输：-1.00

### Q5：胜率低于 50%正常吗？

**A**：考虑到水位（0.90），盈亏平衡点约为 52.6%胜率。实际应用中需要持续优化。

### Q6：可以批量回测吗？

**A**：目前支持单场手动测试，批量回测功能已实现但建议先进行单场测试熟悉流程。

## ⚠️ 注意事项

1. **Cookie 有效性**

   - 定期检查 Cookie 是否过期
   - 过期需重新登录

2. **数据准确性**

   - 确认实际比分正确
   - 确认比赛时间准确

3. **样本代表性**

   - 选择不同类型的比赛
   - 避免只测试某一类型

4. **结果理性分析**
   - 样本量太少可能偏差大
   - 需要长期累积数据
