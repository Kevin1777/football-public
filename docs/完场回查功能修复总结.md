# 完场回查功能修复总结

## ✅ 问题已完全解决

### 问题原因

1. **错误的 API 参数** - 之前使用的参数 `fff=0/1` 不正确
2. **错误的比分字段** - 解析了颜色代码而不是实际比分

### 修复方案

#### 1. API 参数修正

**修复前：**

```python
payload = {
    "year": str(target_date.year),
    "month": str(target_date.month),
    "day": str(target_date.day),
    "page": "1",
    "fff": "1" if target_date.weekday() in (5, 6) else "0",  # ❌ 错误
    "rows": str(rows),
}
```

**修复后：**

```python
payload = {
    "year": str(target_date.year),
    "month": str(target_date.month),
    "day": str(target_date.day),
    "page": "1",
    "fff": "4",  # ✅ 正确：4表示足球完场回查
}
```

#### 2. 比分解析修正

**修复前：**

```python
score = _first(item, ["score", "Score"]) or (info_parts[2] if len(info_parts) > 2 else None)
# ❌ info_parts[2] 是颜色代码，不是比分
```

**修复后：**

```python
# ✅ info_parts[8] 是主队进球，info_parts[9] 是客队进球
score = None
if len(info_parts) > 9:
    home_goals = info_parts[8].strip()
    away_goals = info_parts[9].strip()
    if home_goals and away_goals and home_goals.isdigit() and away_goals.isdigit():
        score = f"{home_goals}-{away_goals}"
```

### 使用方法

#### 网页端使用

1. 访问 `http://127.0.0.1:5001/collect`
2. 在"📅 完场回查"卡片中选择日期
3. 点击"查询完场"
4. 选择需要的比赛点击"抓取明细"
5. 数据自动解析并可下载

#### API 调用

```python
from datetime import datetime
from services import BifawClient

client = BifawClient()

# 查询指定日期的完场比赛
matches = client.fetch_finished_matches(
    target_date=datetime(2025, 11, 16),
    rows=200
)

print(f"找到 {len(matches)} 场比赛")
for match in matches:
    print(f"{match['label']} - {match['score']}")
```

### 技术细节

#### 发现过程

1. 使用 Selenium 访问完场回查页面
2. 注入 JavaScript 监听网络请求
3. 捕获真实 API 调用：`serveodds.php?year=2025&month=11&day=14&page=1&fff=4`
4. 分析响应数据结构，找到正确的字段映射

#### API 端点

- **URL**: `https://www.bifaw.com/bifaw/serveodds.php`
- **方法**: POST
- **参数**:
  - year: 年份
  - month: 月份（1-12）
  - day: 日期
  - page: 页码（通常为 1）
  - fff: 类型（4=足球完场）

#### 数据结构

响应格式为字典，每个键对应一场比赛：

```json
{
  "a34958428": {
    "info": "847,墨西甲,#999011,1763344800,坦皮科马德罗,哥达拿查拉大学,34958428,...,6,4,...",
    "macth": "...",
    "ou": [...]
  }
}
```

info 字段索引：

- [1]: 联赛名
- [3]: 时间戳
- [4]: 主队
- [5]: 客队
- [6]: 比赛ID
- [8]: 主队进球
- [9]: 客队进球
