# 回测功能使用说明

## 📖 功能概述

回测功能允许你使用**历史比赛数据**来验证推荐引擎的准确性。通过完场回查获取已结束比赛的交易明细，生成推荐，然后与实际结果对比，计算准确率和盈亏。

## 🎯 回测流程

```
1. 完场回查 → 2. 获取明细 → 3. 生成推荐 → 4. 对比结果 → 5. 统计盈亏
```

### 方式 2：API 调用

```python
import requests

response = requests.post(
    "http://127.0.0.1:5001/api/backtest/single",
    json={
        "match": {
            "home": "曼联",
            "away": "利物浦",
            "league": "英超",
            "kickoff": "2025-11-10 20:00"
        },
        "detail_url": "https://...",  # 从完场回查获取
        "actual_score": [2, 1]  # 主队2:1客队
    }
)

result = response.json()

if result["success"]:
    print(result["backtest_report"])

    validation = result["validation"]
    print(f"结果：{validation['result']}")
    print(f"盈亏：{validation['profit']:+.2f}")
```

```python

```

## 💰 盈亏计算规则

### 计算方法

以推荐"客队受让 0.5"为例：

**实际比分：主队 2:1 客队**

```
客队得分 + 让球数 vs 主队得分
1 + 0.5 = 1.5 vs 2
1.5 < 2 → 客队输
```

### 结果类型

| 结果      | 说明 | 盈亏（1 单位） | 水位 0.90  |
| --------- | ---- | -------------- | ---------- |
| WIN       | 全赢 | +0.90          | 赢水位     |
| HALF_WIN  | 半赢 | +0.45          | 赢一半水位 |
| DRAW      | 走水 | 0.00           | 退回本金   |
| HALF_LOSE | 半输 | -0.50          | 输一半本金 |
| LOSE      | 全输 | -1.00          | 输全部本金 |

### 让球盘口结果判定

#### 全赢/全输

- 让球后净胜 ≥0.5 球 → 全赢
- 让球后净负 ≥0.5 球 → 全输

#### 半赢/半输（特殊盘口）

- 让球后净胜 0.25 球 → 半赢
- 让球后净负 0.25 球 → 半输

#### 走水

- 让球后净胜/净负 0 球 → 走水

### 示例计算

#### 示例 1：推荐"主队让球-1.5"

**实际比分：3:0**

```
主队得分 - 让球数 vs 客队得分
3 - 1.5 = 1.5 vs 0
1.5 > 0 → 主队让球成功 → 全赢
盈亏：+0.90
```

#### 示例 2：推荐"客队受让+0.25"

**实际比分：2:1**

```
客队得分 + 让球数 vs 主队得分
1 + 0.25 = 1.25 vs 2
1.25 < 2 → 客队受让失败 → 半输
盈亏：-0.50
```

#### 示例 3：推荐"主队让球-1.0"

**实际比分：1:0**

```
主队得分 - 让球数 vs 客队得分
1 - 1.0 = 0 vs 0
0 = 0 → 走水
盈亏：0.00
```

## 📈 统计指标

### 胜率计算

```python
胜率 = (全赢场次 + 半赢场次 × 0.5) / 推荐总场次 × 100%
```

### ROI 计算

```python
ROI = 总盈亏 / 总投入 × 100%
```

其中：

- 总投入 = 推荐场次 × 1 单位
- 总盈亏 = Σ(每场盈亏)

### 示例

**10 场回测结果**：

- 全赢：4 场
- 半赢：2 场
- 走水：1 场
- 半输：1 场
- 全输：2 场

```
胜率 = (4 + 2×0.5) / 10 × 100% = 50%

盈亏：
4×0.90 + 2×0.45 + 1×0 + 1×(-0.50) + 2×(-1.00)
= 3.60 + 0.90 + 0 - 0.50 - 2.00
= 2.00

ROI = 2.00 / 10 × 100% = 20%
```

## 📝 如何获取完场回查明细

### 步骤 1：登录必发网站

确保已登录必发网站（Cookie 有效）

### 步骤 2：访问完场回查

进入完场回查页面，搜索想要回测的比赛

### 步骤 3：获取明细 URL

找到比赛后，点击"查看明细"或类似链接，复制 URL

### 步骤 4：记录实际比分

从比赛结果中记录实际比分（主队得分:客队得分）

### 步骤 5：执行回测

使用获取的 URL 和比分执行回测

## 🎓 使用技巧

### 1. 选择代表性样本

- 选择不同联赛的比赛
- 选择不同时间段的比赛
- 包含强队对弱队、强强对话等不同类型

### 2. 样本数量建议

- 最少：20-30 场
- 推荐：50-100 场
- 理想：200+场

### 3. 结果分析

- 关注胜率和 ROI 两个指标
- 分析失败案例，找出规律
- 根据回测结果调整参数

### 4. 持续优化

- 定期回测新比赛
- 累积样本数据
- 优化推荐策略

## ⚠️ 注意事项

### 1. 数据完整性

- 确保交易明细数据完整
- 确保让球盘口数据准确
- 实际比分必须准确

### 2. Cookie 有效性

- 完场回查需要登录状态
- Cookie 过期会导致获取失败
- 定期更新 Cookie

### 3. 盈亏仅供参考

- 回测盈亏基于简化模型
- 实际投注需考虑更多因素
- 水位可能实时变化

### 4. 样本偏差

- 历史数据不代表未来
- 回测结果可能存在过拟合
- 需要持续验证和调整

## 🔧 故障排除

### 问题 1：无法获取交易明细

**原因**：Cookie 过期或 URL 错误

**解决**：

1. 重新登录必发网站
2. 更新 Cookie
3. 确认 URL 正确

### 问题 2：让球盘口数据缺失

**原因**：500 彩票网没有该比赛数据

**解决**：

1. 确认比赛信息正确（球队名称、日期）
2. 尝试其他数据源
3. 手动输入盘口数据（后续功能）

### 问题 3：推荐生成失败

**原因**：数据不完整或熔断触发

**解决**：

1. 检查数据采集状态
2. 查看熔断原因
3. 确认比赛信息完整
