## 🎯 策略 1：分级阈值（最推荐）⭐⭐⭐⭐⭐

### 核心思路

不同类型比赛用不同阈值：

- **高质量比赛**（数据完整、热门联赛）→ **降低阈值到 0.75**
- **普通比赛** → 保持 0.80
- **低质量比赛** → 提高到 0.85

### 实现方案

```python
def get_confidence_threshold(match_info: Dict, metrics: Dict) -> float:
    """动态计算置信度阈值"""

    base_threshold = 0.80

    # 🔥 质量加分项（可降低阈值）
    adjustments = []

    # 1. 联赛等级（最重要）
    league = match_info.get('league', '')
    if any(l in league for l in ['英超', '西甲', '德甲', '意甲', '法甲', '欧冠']):
        adjustments.append(-0.05)  # S级：降5%
    elif any(l in league for l in ['英冠', '荷甲', '葡超', '中超']):
        adjustments.append(-0.03)  # A级：降3%

    # 2. 成交量（数据可靠性）
    total_volume = metrics.get('total_volume', 0)
    if total_volume > 500000:
        adjustments.append(-0.03)  # 大热门：降3%
    elif total_volume > 200000:
        adjustments.append(-0.02)  # 热门：降2%
    elif total_volume < 50000:
        adjustments.append(+0.05)  # 冷门：升5%

    # 3. 数据完整性
    if metrics.get('bfindex_home', 0) > 0 and metrics.get('kelly_home', 0) > 0:
        adjustments.append(-0.02)  # 数据完整：降2%

    # 4. FLM+SPM一致性（信号强度）
    if metrics.get('flm_spm_consistent', False):  # 两者方向一致
        adjustments.append(-0.03)  # 信号强：降3%

    # 🔥 计算最终阈值
    final_threshold = base_threshold + sum(adjustments)

    # 限制在合理范围
    return max(0.70, min(0.90, final_threshold))
```

### 预期效果

```
S级联赛 (阈值0.75): 准确率81%, 增加50场
A级联赛 (阈值0.77): 准确率82%, 增加30场
普通比赛 (阈值0.80): 准确率83%, 保持原样
低质量   (阈值0.85): 准确率85%, 减少推荐

总计: 推荐量从277 → 360场 (+30%)
整体准确率: 82% (略降1%)
```

### 选择策略

```python
def select_best_recommendation(recs: List[Dict]) -> Dict:
    """选择最佳推荐"""

    # 策略1：选置信度最高的
    highest_conf = max(recs, key=lambda r: r.get('confidence', 0))

    # 策略2：选多数投票
    directions = [r.get('direction') for r in recs if r.get('direction') != 'none']
    if directions:
        from collections import Counter
        most_common = Counter(directions).most_common(1)[0][0]

        # 如果3个以上一致，置信度提升
        if directions.count(most_common) >= 3:
            return {
                'direction': most_common,
                'confidence': min(highest_conf['confidence'] * 1.1, 0.95),
                'reason': f'多时段一致推荐({directions.count(most_common)}/4)'
            }

    return highest_conf
```
