   - 足球比赛本身的不确定性

3. **数据时效性**
   - 临场伤病、阵容调整等因素
   - JSON 数据可能不是最新

### 改进建议

1. ✅ **只跟高置信度** (≥0.85)
2. ✅ **避开风控触发的比赛**
3. ✅ **关注 FLM="强热支持"的比赛**
4. ⚠️ **谨慎对待中等置信度** (0.70-0.80)
