### 2. 比分来源 - 文件名编码

**比分不在 JSON 内容中，而是在文件名中**！

**文件命名规则**:

```
2025-11-25_欧联U19_曼彻斯特城U19_vs_勒沃库森U19_2_0_2300.json
                                                    ↑ ↑
                                            主队得分 客队得分
```

**从文件名提取比分** (`recommendation_tracker.py` 第 338 行):

```python
def _extract_score_from_filename(self, filename: str) -> Optional[tuple]:
    """从文件名提取比分"""
    import re
    pattern = r'_(\d+)_(\d+)_\d{4}\.json$'
    match = re.search(pattern, filename)
    if match:
        return (int(match.group(1)), int(match.group(2)))
    return None
```

**时间线**:

1. **推荐时**: 引擎只读取 JSON 内容（盘口、成交量等），**不知道文件名**
2. **审查时**: 才从文件名提取比分，对比推荐结果
