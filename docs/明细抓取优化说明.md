# 明细抓取优化说明

## 解决的问题

### 1. **新窗口打开问题**

- **问题**：明细按钮点击后会在新窗口打开页面，原有的 requests 方法无法处理
- **解决方案**：使用 Selenium 浏览器自动化，通过 `window.open()` 模拟新窗口打开，并自动切换到新窗口进行抓取

### 2. **登录状态延续**

- **问题**：新打开的明细页面可能无法保持登录状态
- **解决方案**：
  - 在打开明细页面前先访问主页并验证登录状态
  - 使用已保存的 cookies 注入到新窗口
  - 通过 `_login_ready()` 检查确保登录成功

### 3. **调试截图功能**

- **问题**：抓取失败时难以定位问题
- **解决方案**：在关键步骤自动保存截图到 `debug_html/` 目录：
  - `detail_login_failed_*.png` - 登录验证失败时
  - `detail_page_loaded_*.png` - 页面加载后
  - `detail_keyword_found_*.png` - 找到关键字后
  - `detail_timeout_*.png` - 超时时
  - `detail_success_*.png` - 成功抓取时
  - 同时保存对应的 HTML 文件用于分析

## 新增的核心方法

### `BifawClient.fetch_match_detail_selenium()`

使用 Selenium 浏览器抓取标盘明细页面。

**参数：**

- `detail_url` - 明细页面链接
- `match` - 比赛信息字典
- `detail_params` - 明细参数
- `wait_text` - 等待的关键字（默认：买家挂牌、卖家挂牌等）
- `timeout` - 超时时间（默认 40 秒）

**返回：**

- 明细页面的 HTML 源码

**特性：**

1. 自动处理新窗口打开
2. 验证登录状态
3. 自动在 iframe 中搜索内容
4. 全流程自动截图
5. 详细的错误信息

### `BifawClient._save_debug_screenshot()`

保存调试截图到 debug 目录。

**参数：**

- `driver` - Selenium WebDriver 对象
- `prefix` - 文件名前缀

**返回：**

- 截图文件路径

## API 接口变更

### `/api/bifaw/match_detail` [POST]

**新增参数：**

- `use_selenium` (boolean, 默认 true) - 是否使用 Selenium 方法
  - `true` - 使用 Selenium（推荐，支持新窗口和自动截图）
  - `false` - 使用原有 requests 方法（备用）

**成功响应示例：**

```json
{
  "success": true,
  "message": "标盘明细抓取成功（已自动保存截图到debug目录）。",

  "csv_data": "base64...",
  "report_text": "...",
  "report_data": "base64...",
  "label": "比赛标签"
}
```

## 使用说明

访问 `http://127.0.0.1:5001/collect`：

1. **首次使用**：点击"获取验证码"并完成登录

3. **抓取明细**：在场次列表中点击"抓取明细"按钮
4. 系统会自动：
   - 使用 Selenium 打开明细页面
   - 处理新窗口
   - 在关键步骤保存截图

### 2. 调试失败的抓取

如果抓取失败：

1. **查看截图**：进入 `d:\MSM\Cursor\football\debug_html\` 目录
2. **按时间排序**：找到最新的截图和 HTML 文件
3. **分析问题**：
   - `detail_login_failed` - 登录状态问题
   - `detail_timeout` - 页面加载超时
   - `detail_timeout_no_keyword` - 页面加载成功但内容不匹配

## 技术细节

### 新窗口处理流程

1. **保存初始窗口句柄**

   ```python
   original_window = driver.current_window_handle
   initial_windows = set(driver.window_handles)
   ```

2. **打开新窗口**

   ```python
   driver.execute_script(f"window.open('{target}', '_blank');")
   ```

3. **等待新窗口出现**

   ```python
   WebDriverWait(driver, 10).until(
       lambda d: len(set(d.window_handles)) > len(initial_windows)
   )
   ```

4. **切换到新窗口**

   ```python
   new_windows = set(driver.window_handles) - initial_windows
   if new_windows:
       driver.switch_to.window(new_windows.pop())
   ```

5. **完成后清理**
   ```python
   driver.close()  # 关闭新窗口
   driver.switch_to.window(original_window)  # 切回原窗口
   ```

### 登录状态验证

在访问明细页面前，会：

1. 访问主页 `/bifaw/index.php`
2. 检查页面中是否有"登录"和"验证码"字样
3. 检查是否有"退出登录"链接
4. 如果验证失败，自动保存截图和 HTML 用于调试

### iframe 内容搜索

使用深度优先搜索（DFS）遍历所有 iframe：

```python
def _dfs() -> Optional[str]:
    html_content = d.page_source
    if any(keyword in html_content for keyword in keywords):
        return html_content

    frames = d.find_elements(By.TAG_NAME, "iframe") + d.find_elements(By.TAG_NAME, "frame")
    for frame in frames:
        d.switch_to.frame(frame)
        nested_html = _dfs()
        if nested_html:
            return nested_html
        d.switch_to.parent_frame()
    return None
```

## 注意事项

1. **Chrome/Chromium 依赖**：需要安装 Chrome 浏览器和 chromedriver
2. **截图存储**：debug 目录的截图会不断累积，建议定期清理
3. **性能**：Selenium 方法比 requests 慢，但更可靠
4. **Headless 模式**：目前运行在无头模式，如需调试可临时关闭

## 故障排查

### 问题：selenium 超时

**可能原因：**

- Chrome/chromedriver 版本不匹配
- 网络问题
- 页面加载过慢

**解决方案：**

1. 检查 debug 目录的截图
2. 增加 `timeout` 参数值
3. 检查网络连接

### 问题：登录状态失效

**可能原因：**

- cookies 过期
- 会话超时

**解决方案：**

1. 在采集控制台重新登录
2. 检查 `cookies.json` 文件
3. 查看 `detail_login_failed` 截图

### 问题：未找到关键字

**可能原因：**

- 页面结构变化
- 内容在 iframe 深层嵌套
- 加载时间不足

**解决方案：**

1. 查看 `detail_timeout_no_keyword` 的截图和 HTML
2. 调整 `wait_text` 参数
3. 增加等待时间
