# 服务器部署指南 🚀

## 📋 部署环境要求

### 系统要求

- **操作系统**：Ubuntu 20.04+ / CentOS 7+ / Debian 10+
- **Python**：3.8+
- **内存**：2GB+
- **磁盘**：10GB+（用于存储数据）

### 必要软件

- Python3
- pip3
- Google Chrome
- ChromeDriver（自动安装）

---

## 🚀 快速部署（推荐）

### 方法 1：使用部署脚本（Linux）

1. **上传代码到服务器**

   ```bash
   # 使用FTP/SFTP或Git上传代码
   scp -r /path/to/football root@服务器IP:/root/
   # 或
   git clone https://github.com/your-repo/football.git
   ```

2. **运行部署脚本**

   ```bash
   cd /root/football
   chmod +x deploy_server.sh
   ./deploy_server.sh
   ```

3. **编辑配置文件**

   ```bash
   # 配置必发网账号
   nano config.json

   # 配置百度OCR（可选）
   nano .env
   ```

4. **启动服务**
   ```bash
   python3 app.py
   ```

## 📝 手动部署步骤

### 步骤 1：上传代码

```bash
# 使用SCP上传
scp -r d:\MSM\Cursor\football root@服务器IP:/root/

# 或使用Git
cd /root
git clone https://github.com/your-repo/football.git
cd football
```

### 步骤 2：安装 Python 依赖

```bash
cd /root/football

# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate

# 升级pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt
```

**如果安装失败，尝试使用国内镜像源：**

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 步骤 3：安装 Chrome 浏览器

#### Ubuntu/Debian

```bash
# 添加Google源
wget -q -O - https://dl-ssl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
sudo sh -c 'echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" >> /etc/apt/sources.list.d/google-chrome.list'

# 更新并安装
sudo apt-get update
sudo apt-get install -y google-chrome-stable

# 验证安装
google-chrome --version
```

#### CentOS/RHEL

```bash
# 下载Chrome
wget https://dl.google.com/linux/direct/google-chrome-stable_current_x86_64.rpm

# 安装
sudo yum install -y ./google-chrome-stable_current_x86_64.rpm

# 验证
google-chrome --version
```

### 步骤 4：配置文件

#### config.json（必发网账号）

```bash
nano config.json
```

内容：

```json
{
  "account": "你的手机号",
  "password": "你的密码"
}
```

#### .env（环境变量，可选）

```bash
cp .env.example .env
nano .env
```

内容：

```bash
# 百度OCR配置（可选）
BAIDU_OCR_ENABLED=1
BAIDU_OCR_API_KEY=你的API_Key
BAIDU_OCR_SECRET_KEY=你的Secret_Key
```

### 步骤 5：创建目录结构

```bash
mkdir -p data/cache data/details data/handicaps debug_html PDF
chmod 755 data debug_html PDF
```

### 步骤 6：测试运行

```bash
# 前台运行（测试用）
python3 app.py
```

访问 `http://服务器IP:5001` 测试是否正常。

## 🔧 解决依赖问题

### 问题 1：ModuleNotFoundError: No module named 'apscheduler'

**解决方案：**

```bash
pip install APScheduler
```

### 问题 2：ModuleNotFoundError: No module named 'services.lottery500_client'

**原因：** Python 路径问题

**解决方案：**

```bash
# 方法1：确保在项目根目录运行
cd /root/football
python3 app.py

# 方法2：设置PYTHONPATH
export PYTHONPATH=/root/football:$PYTHONPATH
python3 app.py

# 方法3：在app.py中添加路径（已包含）
```

### 问题 3：selenium.common.exceptions.WebDriverException: chrome not found

**解决方案：**

```bash
# 安装Chrome（参考步骤3）
sudo apt-get install google-chrome-stable

# 或者手动指定Chrome路径
export CHROME_BIN=/usr/bin/google-chrome
```

### 问题 4：依赖包安装失败

**解决方案：使用国内镜像源**

```bash
# 阿里云镜像
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

# 清华大学镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 🔄 后台运行

### 方法 1：使用 nohup

```bash
nohup python3 app.py > app.log 2>&1 &

# 查看日志
tail -f app.log

# 停止服务
ps aux | grep app.py
kill <PID>
```

### 方法 2：使用 screen

```bash
# 安装screen
sudo apt-get install screen

# 创建会话
screen -S football

# 运行程序
python3 app.py

# 脱离会话：Ctrl+A, D

# 重新连接
screen -r football

# 停止服务：在screen中按 Ctrl+C
```

### 方法 3：使用 systemd（推荐）

创建服务文件：

```bash
sudo nano /etc/systemd/system/football.service
```

内容：

```ini
[Unit]
Description=Football Data Collection Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/football
Environment="PATH=/root/football/venv/bin"
ExecStart=/root/football/venv/bin/python3 /root/football/app.py
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
# 重载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start football

# 开机自启
sudo systemctl enable football

# 查看状态
sudo systemctl status football

# 查看日志
sudo journalctl -u football -f
```

## 🔒 安全配置

### 1. 配置防火墙

```bash
# UFW（Ubuntu）
sudo ufw allow 5001/tcp
sudo ufw reload

# firewalld（CentOS）
sudo firewall-cmd --permanent --add-port=5001/tcp
sudo firewall-cmd --reload
```

### 2. 配置 Nginx 反向代理（可选）

安装 Nginx：

```bash
sudo apt-get install nginx
```

配置文件：

```bash
sudo nano /etc/nginx/sites-available/football
```

内容：

```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/football /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 📊 性能优化

```bash
pip install gunicorn
```

```bash
gunicorn -w 4 -b 0.0.0.0:5001 app:app
```

```ini
[Service]
MemoryLimit=2G

```

## 🐛 故障排查

### 查看日志

```bash
# 应用日志
tail -f app.log

# 系统日志
sudo journalctl -u football -f

# Python错误
python3 -c "import sys; print(sys.path)"
```

### 常见错误

1. **端口占用**

   ```bash
   sudo lsof -i:5001
   sudo kill -9 <PID>
   ```

2. **权限问题**

   ```bash
   chmod 755 app.py
   chown -R $USER:$USER /root/football
   ```

3. **Chrome 进程残留**
   ```bash
   pkill chrome
   pkill chromedriver
   ```
