# 让球盘口数据获取功能说明

## 概述

本系统新增了从 500 彩票网获取让球盘口（亚洲盘）数据的功能。支持单场比赛和批量比赛的盘口数据获取。

## 功能特点

- ✅ **自动盘口解析**：支持中文盘口表示（如"球半"、"受平/半"）和数值表示（如"-1.5"、"+0.25"）
- ✅ **多种博彩公司**：支持澳门盘、皇冠、Bet365、立博等多家公司的盘口数据
- ✅ **批量获取**：支持一次性获取多场比赛的盘口数据
- ✅ **历史数据**：提供盘口变化历史记录
- ✅ **主客队识别**：正确区分主队让球和客队让球

## 盘口数值说明

### 盘口表示对照表

| 中文表示  | 数值 | 说明       |
| --------- | ---- | ---------- |
| 平手      | 0.0  | 不让球     |
| 平/半     | 0.25 | 让 0.25 球 |
| 半球      | 0.5  | 让 0.5 球  |
| 半/一     | 0.75 | 让 0.75 球 |
| 一球      | 1.0  | 让 1 球    |
| 一/球半   | 1.25 | 让 1.25 球 |
| 球半      | 1.5  | 让 1.5 球  |
| 球半/两   | 1.75 | 让 1.75 球 |
| 两球      | 2.0  | 让 2 球    |
| 两/两球半 | 2.25 | 让 2.25 球 |
| 两球半    | 2.5  | 让 2.5 球  |
| 三球      | 3.0  | 让 3 球    |

### 主客队让球说明

- **正数**：主队让球（主队强）
  - 例如：`+1.5` 表示主队让客队 1.5 球
- **负数**：主队受让（客队强）

  - 例如：`-0.5` 表示主队受让客队 0.5 球（即客队让主队 0.5 球）

- **受让表示**：
  - "受平/半" = -0.25（主队受让 0.25 球）
  - "受球半" = -1.5（主队受让 1.5 球）

## API 接口说明

### 1. 搜索比赛 `/api/handicap/search`

根据球队名称搜索 500 彩票网的比赛 ID。

**请求方法**: POST

**请求参数**:

```json
{
  "home_team": "主队名称",
  "away_team": "客队名称",
  "league": "联赛名称（可选）",
  "match_date": "比赛日期 YYYY-MM-DD（可选）"
}
```

**返回示例**:

```json
{
  "success": true,
  "fid": "123456",
  "message": "找到比赛ID: 123456"
}
```

### 2. 获取盘口数据 `/api/handicap/data`

根据比赛 ID 获取让球盘口数据。

**请求方法**: POST

**请求参数**:

```json
{
  "fid": "比赛ID",
  "company_id": "博彩公司ID（可选，默认3=澳门盘）"
}
```

**博彩公司 ID**:

- `3`: 澳门盘
- `31`: 皇冠
- `35`: Bet365
- `4`: 立博

**返回示例**:

```json
{
    "success": true,
    "data": {
        "initial_handicap": -0.5,
        "initial_handicap_str": "受半球",
        "current_handicap": -0.25,
        "current_handicap_str": "受平/半",
        "initial_home_odds": 0.95,
        "initial_away_odds": 0.85,
        "current_home_odds": 0.90,
        "current_away_odds": 0.90,
        "history": [...]
    }
}
```

### 3. 一站式获取 `/api/handicap/match` ⭐ 推荐

最简单的方式，只需提供球队名称即可自动搜索并获取盘口数据。

**请求方法**: POST

**请求参数**:

**返回示例**:

```json
        "league": "英超",

        "initial_away_odds": 0.85,
        "current_home_odds": 0.90,
        "current_away_odds": 0.90,

                "handicap_str": "受半球",
                "handicap": -0.5,
                "away_odds": 0.85
```

### 4. 批量获取 `/api/handicap/batch`

一次性获取多场比赛的盘口数据。

**请求方法**: POST

**请求参数**:

```json
{
  "matches": [
    {
      "home_team": "曼联",
      "away_team": "利物浦"
    },
    {
      "home_team": "切尔西",
      "away_team": "阿森纳"
    }
  ],
  "company_id": "3（可选）"
}
```

**返回示例**:

```json
{
    "success": true,
    "total": 2,
    "success_count": 2,
    "error_count": 0,
    "results": [
        {
            "index": 0,
            "success": true,
            "data": {...}
        },
        {
            "index": 1,
            "success": true,
            "data": {...}
        }
    ],
    "errors": []
}
```

## 使用示例

### Python 示例

```python
import requests

# 1. 一站式获取单场比赛盘口
response = requests.post(
    "http://127.0.0.1:5001/api/handicap/match",
    json={
        "home_team": "曼联",
        "away_team": "利物浦",
        "match_date": "2025-11-18",
        "company_id": "3"
    }
)

result = response.json()
if result["success"]:
    data = result["data"]
    print(f"初盘让球: {data['initial_handicap']} ({data['initial_handicap_str']})")
    print(f"即时盘让球: {data['current_handicap']} ({data['current_handicap_str']})")
    print(f"即时盘水位: {data['current_home_odds']} / {data['current_away_odds']}")

# 2. 批量获取多场比赛盘口
response = requests.post(
    "http://127.0.0.1:5001/api/handicap/batch",
    json={
        "matches": [
            {"home_team": "曼联", "away_team": "利物浦"},
            {"home_team": "切尔西", "away_team": "阿森纳"}
        ]
    }
)

result = response.json()
print(f"成功: {result['success_count']}, 失败: {result['error_count']}")
for r in result['results']:
    data = r['data']
    print(f"{data['home_team']} vs {data['away_team']}: {data['current_handicap_str']}")
```

### JavaScript 示例

```javascript
    }
  });
```

## 集成到现有工作流

### 与比赛列表集成

你可以从必发的比赛列表获取比赛信息，然后获取让球盘口数据：

```python
# 1. 获取必发比赛列表
matches_response = requests.get("http://127.0.0.1:5001/api/bifaw/matches")
matches = matches_response.json()["matches"]

# 2. 为每场比赛获取让球盘口
for match in matches:
    handicap_response = requests.post(
        "http://127.0.0.1:5001/api/handicap/match",
        json={
            "home_team": match["home"],
            "away_team": match["away"],
            "league": match.get("league"),
            "match_date": match.get("kickoff", "").split()[0]
        }
    )

    if handicap_response.json()["success"]:
        handicap_data = handicap_response.json()["data"]
        match["handicap"] = handicap_data["current_handicap"]
        match["handicap_str"] = handicap_data["current_handicap_str"]
```

### 与明细抓取集成

在抓取比赛明细时，可以同时获取让球盘口：

```python
# 1. 抓取比赛明细
detail_response = requests.post(
    "http://127.0.0.1:5001/api/bifaw/match_detail",
    json={
        "detail_url": "...",
        "match": match_info
    }
)

# 2. 获取让球盘口
handicap_response = requests.post(
    "http://127.0.0.1:5001/api/handicap/match",
    json={
        "home_team": match_info["home"],
        "away_team": match_info["away"]
    }
)

# 3. 合并数据
if detail_response.json()["success"] and handicap_response.json()["success"]:
    detail_data = detail_response.json()
    handicap_data = handicap_response.json()["data"]

    # 添加盘口信息到报告
    print(f"让球盘口: {handicap_data['current_handicap_str']}")
```

## 注意事项

1. **球队名称匹配**：

   - 球队名称需要与 500 彩票网上的名称一致或相近
   - 系统会自动清理括号、空格等干扰字符
   - 如果匹配失败，会保存调试 HTML 文件用于排查

2. **主客队识别**：

   - 务必正确区分主队和客队
   - 主队永远是第一个参数`home_team`
   - 让球数正负号基于主队视角

3. **日期格式**：

   - 使用`YYYY-MM-DD`格式（如`2025-11-18`）
   - 如不提供日期，默认使用今天

4. **博彩公司选择**：

   - 不同公司的盘口可能不同
   - 建议使用澳门盘（company_id=3）作为参考

5. **错误处理**：
   - 如果比赛未找到，检查球队名称和日期
   - 查看生成的 debug 文件了解详情
   - 部分比赛可能没有盘口数据

## 常见问题

**Q: 为什么找不到比赛？**

A: 可能原因：

- 球队名称不匹配（尝试简化名称，如"曼彻斯特联"改为"曼联"）
- 比赛日期不对（确认使用正确的比赛日期）
- 该比赛在 500 彩票网上不存在

**Q: 盘口数值和中文表示不一致？**

A: 检查`debug_500_handicap_*.txt`文件，查看原始返回数据。

**Q: 如何理解负数盘口？**

A: 负数表示主队受让：

- `-0.5`：主队受让半球，即客队让主队半球
- `+1.5`：主队让客队球半

**Q: 批量获取时部分失败怎么办？**

A: 返回结果中包含`errors`数组，说明了每个失败比赛的原因。可以单独重试失败的比赛。
