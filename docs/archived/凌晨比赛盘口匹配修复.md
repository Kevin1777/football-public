# 凌晨比赛盘口匹配修复

## 🔴 问题发现

**用户反馈**:

> "我大概知道了你为什么找不到盘口数据的问题了，现在 26 号的凌晨 12 点，你应该读取的是 25 号的盘口数据来匹配让球盘口 而不是读取 26 号的"

---

## 🎯 问题分析

### 现象

- **当前时间**: 2025-11-26 00:25（26 日凌晨）
- **比赛开球**: 2025-11-26 02:00（26 日凌晨 2 点）
- **我的代码**: 从 26 日的盘口数据查找 ❌
- **实际情况**: 500 彩票网将凌晨比赛归类到**25 日** ❌

### 根本原因

**500 彩票网的日期归类规则**：

- 凌晨 0-8 点的比赛通常归类到**前一天**
- 例如：26 日凌晨 2 点的比赛 → 在 25 日的盘口数据中

**我的旧代码逻辑**：

```python
# 错误的做法
match_date = "2025-11-26"  # 从kickoff中提取
daily_handicaps = fetch_daily_handicaps("2025-11-26")  # ❌ 找不到
```

**为什么找不到**：

- 500 彩票网没有 26 日的盘口数据（因为还没到 26 日白天）
- 凌晨比赛的盘口数据在 25 日的数据中

---

## ✅ 解决方案

### 核心思路：智能日期判断

```python
# 新的逻辑
if 比赛时间在凌晨0-8点:
    先尝试从前一天查找盘口
    如果找不到，再尝试当天
else:
    直接从当天查找盘口
```

### 实现细节

#### 1. 检测凌晨比赛

```python
# 检查是否有凌晨比赛（0-8点）
has_early_morning_match = False
for match in date_matches:
    kickoff = match.get('kickoff', '')  # "2025-11-26 02:00"
    if ' ' in kickoff:
        time_part = kickoff.split(' ')[1]  # "02:00"
        hour = int(time_part.split(':')[0])  # 2
        if 0 <= hour < 8:
            has_early_morning_match = True
            break
```

#### 2. 确定搜索日期

```python
search_dates = [match_date]  # 默认：当天

# 如果有凌晨比赛，优先尝试前一天
if has_early_morning_match:
    from datetime import datetime, timedelta
    current_date = datetime.strptime(match_date, '%Y-%m-%d')
    previous_date = (current_date - timedelta(days=1)).strftime('%Y-%m-%d')
    search_dates = [previous_date, match_date]  # 先查前一天，再查当天
```

#### 3. 按顺序查找盘口

```python
daily_handicaps = {}
for search_date in search_dates:
    temp_handicaps = fetch_daily_handicaps(search_date)
    if temp_handicaps:
        daily_handicaps.update(temp_handicaps)  # 合并数据
```

## ⚙️ 时间阈值说明

**凌晨时间定义**: 0:00 - 8:00

**为什么选择 8 点**：

1. 500 彩票网通常在早上 8 点后更新当天数据
2. 0-8 点的比赛大多是欧洲晚场、美洲比赛
3. 这些比赛通常归类在前一天

**可调整性**：

```python
if 0 <= hour < 8:  # 可以修改为其他值
```

## 📝 注意事项

### 1. 数据合并策略

```python
daily_handicaps.update(temp_handicaps)
```

- 使用 `update()` 合并字典
- 如果两个日期有相同的比赛，后面的会覆盖前面的
- 由于是按 [前一天, 当天] 的顺序，当天的数据优先级更高

### 2. 性能影响

- 凌晨比赛：需要查询 2 个日期（增加 1 次请求）
- 非凌晨比赛：只查询 1 个日期（无影响）
- 使用缓存机制减少重复请求

### 3. 边界情况

**午夜零点的比赛**：

```
26日 00:00 的比赛
→ hour = 0
→ 0 <= 0 < 8 为 True
→ 会从25日和26日查找
```

**早上 8 点整的比赛**：

```
26日 08:00 的比赛
→ hour = 8
→ 0 <= 8 < 8 为 False
→ 只从26日查找
```
