# 盘口识别修复说明

## 🔴 问题描述

从日志中看到大量"无法识别盘口"的警告，这是由于**500 彩票网的 HTML 结构发生变化**导致的。

---

## ✅ 修复方案

### 1. 增强盘口提取正则表达式

现在支持**7 种匹配模式**，以应对 500 彩票网的各种 HTML 格式变化：

| 模式 | 匹配规则            | 适用场景                     |
| ---- | ------------------- | ---------------------------- |
| 1    | `class="fhuise"`    | 完场页面格式（灰色）         |
| 2    | `class="fgreen"`    | 系统彩页面格式（绿色）       |
| 3    | `class="fred"`      | 新增红色盘口格式             |
| 4    | 任意颜色 class      | 通用匹配（blue/orange 等）   |
| 5    | `data-ao`属性       | 备用数据属性                 |
| 6    | pk div 中的链接文本 | 智能提取包含盘口关键字的文本 |
| 7    | pk div 中的纯文本   | 最宽松匹配（兜底）           |

### 2. 启用 HTML 保存功能

已临时启用 HTML 保存，位置：

```
data/YYYY/MM/DD/盘口数据.html
```

这样可以查看实际的 HTML 结构，便于调试。

## 🛠️ 手动修复示例

如果发现新的 HTML 格式，例如：

```html
<div class="pk">
  <a class="fnew">球半</a>
</div>
```

添加新的匹配模式：

```python
# 🔥 模式8: 新格式 class="fnew"
pk_match = re.search(r'<div class="pk">.*?class="fnew"[^>]*>([^<]+)</a>', context, re.DOTALL)
if pk_match:
    result = pk_match.group(1).strip()
    if result and result != '-':
        return result
```
