#### 1. 添加动态阈值计算方法（第 443 行）

```python
def _calculate_dynamic_threshold(self, metrics: Dict, funding_level: Dict) -> float:
    """动态计算置信度阈值"""
    base_threshold = 0.80
    adjustments = 0

    # 成交量调整
    if volume > 500000: adjustments -= 0.03
    elif volume > 200000: adjustments -= 0.02
    elif volume < 50000: adjustments += 0.05

    # 数据质量调整
    if data_quality == 3: adjustments -= 0.02
    elif data_quality < 2: adjustments += 0.03

    # 资金等级调整
    if sbre_weight >= 0.85: adjustments -= 0.02
    elif sbre_weight <= 0.35: adjustments += 0.03

    return max(0.70, min(0.90, base_threshold + adjustments))
```

## 🔍 动态阈值工作原理

### 示例 1：英超大热门

```python
比赛: 英超 曼城 vs 利物浦
成交量: 600,000 (超大热度)
数据质量: 完整
资金等级: L1 (SBRE=1.0)

调整:
- 超大热度: -3%
- 数据完整: -2%
- L1热门: -2%
总计: -7%

最终阈值: 0.80 - 0.07 = 0.73

效果: 更容易推荐高质量比赛
```

### 示例 2：低级别冷门

```python
比赛: 瑞典甲 某队 vs 某队
成交量: 30,000 (冷门)
数据质量: 不完整
资金等级: L5 (SBRE=0.15)

调整:
- 冷门: +5%
- 数据不完整: +3%
- L5冷门: +3%
总计: +11%

最终阈值: 0.80 + 0.11 = 0.90

效果: 更严格过滤低质量比赛
```
