## 📊 修复的问题

### 问题："未找到比赛数据"

#### 原因：

```python
# 修复前：要求label中必须有比分
if match_info and match_info.get("label"):
    # 只有label存在才加载
```

#### 修复后：

```python
# 修复后：只要有match_info就可以
if match_info:  # 不要求label必须存在
    # 提取比分（如果有）
    label = match_info.get("label", "")
    score_match = re.search(r'(\d+)-(\d+)', label) if label else None
```
