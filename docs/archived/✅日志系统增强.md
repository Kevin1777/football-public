# ✅ 日志系统增强 - 解决批量回测日志缺失

## 🔍 问题诊断

### 发现的问题

1. ❌ **日志只输出到控制台**

   ```python
   # 原来的配置
   logging.basicConfig(
       level=logging.INFO,
       format='%(asctime)s [%(levelname)s] %(message)s',
       datefmt='%H:%M:%S'
   )
   ```

   - 只配置了控制台输出
   - 终端关闭后日志丢失
   - 无法回溯批量回测过程

2. ❌ **批量回测日志缺失**

   - 推荐决策日志没有保存
   - 无法看到`dynamic_threshold`的值
   - 无法调试准确率问题

3. ❌ **日志编码问题**
   - 中文日志显示乱码
   - `鉁?` 这种字符无法正常显示

---

## ✅ 修复方案

### 新的日志配置

**文件**: `app.py` 第 49-54 行

**修改后的配置**:

```python
# 🔥 配置日志输出到控制台 + 文件（记录所有终端信息）
import sys
from logging.handlers import RotatingFileHandler

# 确保logs目录存在
Path("logs").mkdir(exist_ok=True)

# 配置根日志记录器
root_logger = logging.getLogger()
root_logger.setLevel(logging.INFO)
root_logger.handlers.clear()

# 1. 控制台处理器（终端输出）
console_handler = logging.StreamHandler(sys.stdout)
console_handler.setLevel(logging.INFO)
console_formatter = logging.Formatter(
    '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    datefmt='%Y-%m-%d %H:%M:%S'
)
console_handler.setFormatter(console_formatter)
root_logger.addHandler(console_handler)

# 2. 文件处理器（保存所有日志到文件）
file_handler = RotatingFileHandler(
    'logs/app_full.log',  # 完整日志文件
    maxBytes=50*1024*1024,  # 50MB
    backupCount=5,
    encoding='utf-8'  # ✅ 修复编码问题
)
file_handler.setLevel(logging.DEBUG)  # ✅ 文件记录DEBUG级别
file_formatter = logging.Formatter(
    '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    datefmt='%Y-%m-%d %H:%M:%S'
)
file_handler.setFormatter(file_formatter)
root_logger.addHandler(file_handler)

# 3. 批量回测专用日志文件
backtest_handler = RotatingFileHandler(
    'logs/backtest_detail.log',  # ✅ 批量回测详细日志
    maxBytes=50*1024*1024,
    backupCount=3,
    encoding='utf-8'
)
backtest_handler.setLevel(logging.DEBUG)
backtest_handler.setFormatter(file_formatter)
# 只给backtest和recommendation模块添加此处理器
logging.getLogger('backtest').addHandler(backtest_handler)
logging.getLogger('recommendation').addHandler(backtest_handler)
```

## 📝 技术细节

### 为什么需要 3 个处理器？

1. **控制台处理器** (`sys.stdout`)

   - 实时查看运行状态
   - 开发调试用

2. **完整日志文件** (`app_full.log`)

   - 记录所有模块的日志
   - 包括 Web 请求、数据采集、推荐生成等
   - 用于系统级排查

3. **批量回测专用日志** (`backtest_detail.log`) ⭐
   - **只记录批量回测和推荐引擎的日志**
   - 包含`推荐决策`、`dynamic_threshold`等关键信息
   - 专门用于分析准确率问题

### 日志级别说明

| 级别    | 控制台 | app_full.log | backtest_detail.log |
| ------- | ------ | ------------ | ------------------- |
| DEBUG   | ❌     | ✅           | ✅                  |
| INFO    | ✅     | ✅           | ✅                  |
| WARNING | ✅     | ✅           | ✅                  |
| ERROR   | ✅     | ✅           | ✅                  |

**控制台**：只显示 INFO 及以上，避免太多信息  
**文件**：记录 DEBUG 及以上，保留最详细的信息

### RotatingFileHandler

自动轮转日志文件：

- 当文件达到 50MB 时，自动重命名为`.log.1`
- 保留最近 5 个备份
- 防止单个日志文件过大
