# ✅ 路由修复完成 - 主页面现在包含批量回测

## 🔥 问题原因

之前访问 `http://localhost:5001` 时，显示的是**采集控制台**（`collect.html`），不是我们修改的 `index.html`。

所以看不到批量回测 Tab。

---

## ✅ 已修复

### 路由调整

#### 修改前：

```python
@app.route("/")
@app.route("/collect")
def index():
    return render_template("collect.html")  # 采集控制台
```

#### 修改后：

```python
@app.route("/")
def index():
    """主页面 - PDF解析 + 批量回测"""
    return render_template("index.html")  # 带批量回测Tab的主页

@app.route("/collect")
def collect_page():
    """采集控制台"""
    return render_template("collect.html")  # 采集控制台移到 /collect
```

---

## 🎯 现在的路由结构

| URL                 | 页面                  | 功能                               |
| ------------------- | --------------------- | ---------------------------------- |
| **/** (根路径)      | `index.html`          | **PDF 解析 + 批量回测** (2 个 Tab) |
| **/collect**        | `collect.html`        | 采集控制台                         |
| **/data-manager**   | `data_manager.html`   | 数据管理                           |
| **/batch-backtest** | `batch_backtest.html` | 独立批量回测页面（已废弃）         |
