# 盘口匹配优化说明

## 🎯 优化目标

解决球队名称不一致导致的盘口数据匹配失败问题。

## 📊 问题案例

**原问题**：

```
比赛：墨西哥美洲 vs 莱昂
结果：未找到比赛
原因：500彩票网可能使用简称"美洲"而不是"墨西哥美洲"
```

## ✨ 优化方案

### 三重匹配验证

```
球队名称（模糊匹配）+ 联赛名称 + 比赛时间
```

### 1. 球队名称模糊匹配

#### 匹配策略：

**策略 A：完全匹配**

```
"墨西哥美洲" in "墨西哥美洲 vs 莱昂"
```

**策略 B：去除国家前缀**

```
"墨西哥美洲" -> "美洲"
"美洲" in "美洲 vs 莱昂"  ✅
```

**策略 C：核心队名匹配**

```
"墨西哥美洲" -> 取后3个字 "美洲"
"美洲" in "美洲 vs 莱昂"  ✅
```

#### 支持的国家/地区前缀：

- 墨西哥、阿根廷、巴西
- 中国、日本、韩国
- 西班牙、英格兰、意大利、德国、法国

### 2. 联赛名称验证

#### 联赛简化映射：

```python
'墨西联' -> '墨超'
'墨西哥超级联赛' -> '墨超'
'英格兰超级联赛' -> '英超'
'西班牙甲级联赛' -> '西甲'
...
```

#### 匹配加分机制：

- ✅ 联赛匹配：+50 分
- ❌ 联赛不匹配：-20 分

### 3. 综合评分系统

#### 评分规则：

| 匹配项                   | 得分 |
| ------------------------ | ---- |
| 双方球队都匹配           | +100 |
| 只匹配一方球队           | +30  |
| 联赛名称匹配             | +50  |
| 联赛名称不匹配           | -20  |
| 球队名称完全匹配（主队） | +20  |
| 球队名称完全匹配（客队） | +20  |

#### 最低分数要求：

```
至少100分（即双方球队都必须匹配）
```

## 🔄 工作流程

```
1. 提取所有候选比赛
   ↓
2. 对每个候选进行评分
   ├─ 球队名称模糊匹配
   ├─ 联赛名称验证
   └─ 时间范围验证（未来可扩展）
   ↓
3. 选择得分最高的候选
   ↓
4. 验证最低分数要求
   ↓
5. 返回匹配结果
```

## ✅ 总结

通过**球队名称模糊匹配 + 联赛验证 + 综合评分**的三重机制，大大提高了盘口数据的匹配准确率。

现在即使球队名称有差异，只要联赛和时间正确，系统也能准确找到对应的比赛盘口数据！
