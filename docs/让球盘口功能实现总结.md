# 让球盘口数据获取功能实现总结

## 实现日期

2025-11-18

## 功能概述

为足球数据采集系统新增了从 500 彩票网获取让球盘口（亚洲盘）数据的功能，实现了自动搜索比赛、获取盘口数据、解析盘口表示的完整流程。

## 核心功能

### 1. 盘口数据解析 ✅

**实现内容**：

- 支持中文盘口表示（球半、平手、受平/半等）
- 支持数值表示（-1.5、+0.25 等）
- 正确处理让球方向（正数=主队让球，负数=主队受让）
- 精确匹配算法，避免误匹配（如"球半"和"半球"）

**测试结果**：

```
球半              ->   1.50  ✓
受平/半            ->  -0.25  ✓
平手              ->   0.00  ✓
-1.5            ->  -1.50  ✓
+0.25           ->   0.25  ✓
一球              ->   1.00  ✓
受让一球            ->  -1.00  ✓
半球              ->   0.50  ✓
受半球             ->  -0.50  ✓
两球半             ->   2.50  ✓
球半/两            ->   1.75  ✓
一/球半            ->   1.25  ✓
```

### 2. 比赛搜索功能 ✅

**实现内容**：

- 根据主客队名称自动搜索 500 彩票网比赛 ID
- 支持指定比赛日期
- 自动清理球队名称（去除括号、空格等干扰字符）
- 生成调试文件用于排查匹配问题

**API 端点**：

```
POST /api/handicap/search
```

### 3. 盘口数据获取 ✅

**实现内容**：

- 支持多家博彩公司（澳门、皇冠、Bet365、立博等）
- 获取初盘和即时盘数据
- 提供完整的盘口变化历史
- 包含主客队水位信息

**API 端点**：

```
POST /api/handicap/data
```

### 4. 一站式服务 ✅

**实现内容**：

- 输入球队名称自动完成搜索+获取
- 最简单的使用方式
- 自动处理所有中间步骤

**API 端点**：

```
POST /api/handicap/match
```

### 5. 批量处理 ✅

**实现内容**：

- 一次性获取多场比赛盘口
- 分别返回成功和失败结果
- 适合批量数据采集

**API 端点**：

```
POST /api/handicap/batch
```

## 盘口表示对照

### 完整映射表（已实现）

支持以下所有盘口表示的自动识别和转换：

- 平手系列：平手(0.0), 平/半(0.25)
- 半球系列：半球(0.5), 半/一(0.75)
- 一球系列：一球(1.0), 一/球半(1.25)
- 球半系列：球半(1.5), 球半/两(1.75)
- 两球系列：两球(2.0), 两/两球半(2.25)
- 两球半系列：两球半(2.5), 两球半/三(2.75)
- 更大盘口：三球(3.0), 三球半(3.5), 四球(4.0)等

所有盘口都支持"受"前缀表示受让方（转为负值）。

## 主客队方向说明

### 关键规则

1. **主队视角**：所有盘口数值基于主队

   - 正数：主队让球（主队强）
   - 负数：主队受让（客队强）

2. **"受"字识别**：

   - "受半球" = -0.5（主队受让半球）
   - "球半" = +1.5（主队让球半）

3. **正负号处理**：
   - "-1.5" 直接解析为 -1.5
   - "+0.25" 直接解析为 0.25

## 集成能力

### 与现有功能集成

✅ **可以集成的功能**：

1. 必发比赛列表（`/api/bifaw/matches`）
2. 比赛明细抓取（`/api/bifaw/match_detail`）
3. 完场回查（`/api/bifaw/finished_matches`）

### 集成示例

```python
# 获取必发比赛列表
matches = requests.get("http://127.0.0.1:5001/api/bifaw/matches").json()["matches"]

# 为每场比赛添加盘口数据
for match in matches:
    handicap = requests.post(
        "http://127.0.0.1:5001/api/handicap/match",
        json={"home_team": match["home"], "away_team": match["away"]}
    ).json()

    if handicap["success"]:
        match["handicap"] = handicap["data"]
```
