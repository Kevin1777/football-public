## ⚠️ 需要修改的配置

### 1. 监听地址 ⚠️

**当前配置** (`app.py` 第 5588 行):

```python
app.run(host="127.0.0.1", port=5002, debug=True, use_reloader=False)
```

**问题**:

- `127.0.0.1` 只允许本机访问
- 服务器需要从外部访问

**修改为**:

```python
app.run(host="0.0.0.0", port=5002, debug=False, use_reloader=False)
```

**说明**:

- `0.0.0.0` - 允许所有 IP 访问
- `debug=False` - 生产环境关闭调试
- `port=5002` - 可根据需要修改

## 🔧 生产环境配置

### 1. 修改监听地址

**文件**: `app.py` 第 5588 行

```python
# 修改前
app.run(host="127.0.0.1", port=5002, debug=True, use_reloader=False)

# 修改后
app.run(host="0.0.0.0", port=5002, debug=False, use_reloader=False)
```

### 2. 使用 systemd 管理服务

创建服务文件 `/etc/systemd/system/football.service`:

```ini
[Unit]
Description=Football Analysis System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/football
Environment="WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
Environment="BAIDU_OCR_API_KEY=your_api_key"
Environment="BAIDU_OCR_SECRET_KEY=your_secret_key"
ExecStart=/root/football/venv/bin/python /root/football/app.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**启动命令**:

```bash
# 重载配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start football

# 开机自启
sudo systemctl enable football

# 查看状态
sudo systemctl status football

# 查看日志
sudo journalctl -u football -f
```

### 3. 使用 Nginx 反向代理（可选）

server {

## ⚠️ 注意事项

### 1. 防火墙配置

如需外部访问，开放端口：

```bash
# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=5002/tcp
sudo firewall-cmd --reload

# Ubuntu/Debian
sudo ufw allow 5002/tcp
```

### 2. SELinux（如果启用）

```bash
# 临时关闭
sudo setenforce 0

# 或配置允许
sudo setsebool -P httpd_can_network_connect 1
```

### 3. Chrome/Chromium（用于 Selenium）

```bash
# Ubuntu/Debian
sudo apt-get install chromium-browser chromium-chromedriver

# CentOS/RHEL
sudo yum install chromium chromium-chromedriver
```

### 4. 中文字体（用于 matplotlib 图表）

```bash
# Ubuntu/Debian
sudo apt-get install fonts-wqy-microhei fonts-wqy-zenhei

# CentOS/RHEL
sudo yum install wqy-microhei-fonts wqy-zenhei-fonts
```
