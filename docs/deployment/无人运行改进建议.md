### 2. 🏥 **健康检查定时任务**（重要性：⭐⭐⭐⭐）

**现状问题：**

- ❌ 没有主动检查系统健康
- ❌ 问题可能积累到影响功能
- ❌ 磁盘空间、日志大小等无监控

**改进方案：**

✅ **已创建健康检查器** (`utils/health_checker.py`)

**检查项目：**

- 💾 磁盘空间（剩余<5GB 告警）
- 📝 日志文件大小（>100MB 告警）
- 📊 数据更新时间（>24 小时告警）
- ⏰ 调度器运行状态
- 📢 推送系统配置

**集成方式：**

```python
# 在app.py中添加定时任务
from utils.health_checker import HealthChecker

health_checker = HealthChecker(
    data_dir=Path('data'),
    log_dir=Path('logs')
)

def system_health_check():
    """系统健康检查"""
    result = health_checker.run_full_check(
        scheduler=scheduler,
        auto_push_system=auto_push_system
    )

    # 如果有问题，发送告警
    if not result['all_passed']:
        for issue in result['issues']:
            alert_manager.alert_system_error(
                component=issue['component'],
                error_msg=issue['message']
            )

# 每小时执行一次
scheduler.add_job(
    func=system_health_check,
    trigger='interval',
    hours=1,
    id='system_health_check',
    name='系统健康检查'
)
```

**优势：**

- ✅ 主动发现问题
- ✅ 预防性维护
- ✅ 减少突发故障

### 3. 🔄 **自动重试机制增强**（重要性：⭐⭐⭐）

**现状问题：**

- ⚠️ 数据采集失败后不会自动重试
- ⚠️ 推送失败后不会重新尝试

**改进方案：**

**a) 数据采集重试**

```python
def auto_collect_today_matches():
    """自动采集今天的比赛（带重试）"""
    max_retries = 3
    retry_delay = 300  # 5分钟

    for attempt in range(max_retries):
        try:
            # 原有采集逻辑
            return
        except Exception as e:
            if attempt < max_retries - 1:
                app.logger.warning(f"采集失败，{retry_delay}秒后重试...")
                time.sleep(retry_delay)
            else:
                alert_manager.alert_data_collection_failed(str(e))
                raise
```

**b) 推送失败重试队列**

```python
# 维护失败推送队列
failed_pushes = []

def retry_failed_pushes():
    """重试失败的推送"""
    global failed_pushes

    for push_info in failed_pushes[:]:
        try:
            # 重新尝试推送
            auto_push_system._send_pre_match_recommendation(...)
            failed_pushes.remove(push_info)
        except Exception as e:
            logger.warning(f"重试推送失败: {e}")

# 每30分钟重试一次
scheduler.add_job(
    func=retry_failed_pushes,
    trigger='interval',
    minutes=30
)
```

```python
def backup_important_data():
    """备份重要数据到云存储"""
    import zipfile
    from datetime import datetime

    # 创建备份
    backup_name = f"backup_{datetime.now().strftime('%Y%m%d')}.zip"

    with zipfile.ZipFile(backup_name, 'w') as zipf:
        # 备份标盘数据
        for file in Path('data').rglob('标盘指数_latest.json'):
            zipf.write(file)

        # 备份推送历史
        zipf.write('pre_match_pushed.json')

    # 上传到云存储（可选：阿里云OSS、腾讯云COS等）
    # upload_to_cloud(backup_name)

# 每天凌晨4点备份
scheduler.add_job(
    func=backup_important_data,
    trigger=CronTrigger(hour=4, minute=0)
)
```

**b) 本地循环备份**

```python
# 保留最近3天的备份
def cleanup_old_backups(keep_days=3):
    backup_dir = Path('backups')
    cutoff_time = datetime.now() - timedelta(days=keep_days)

    for backup_file in backup_dir.glob('backup_*.zip'):
        if backup_file.stat().st_mtime < cutoff_time.timestamp():
            backup_file.unlink()
```

### 5. 🔐 **凭证管理增强**（重要性：⭐⭐⭐）

**现状问题：**

- ⚠️ 账号密码可能过期
- ⚠️ OCR 余额可能用尽

**改进方案：**

**a) 凭证有效性检查**

```python
def check_credentials_validity():
    """检查凭证有效性"""
    issues = []

    # 检查OCR余额
    try:
        ocr_balance = baidu_ocr.get_balance()
        if ocr_balance < 100:
            issues.append(f"OCR余额不足: {ocr_balance}")
    except:
        pass

    # 检查登录有效期
    last_login = bifaw_client._last_successful_login_time
    if last_login:
        days_since_login = (datetime.now() - last_login).days
        if days_since_login > 7:
            issues.append(f"已{days_since_login}天未登录")

    if issues:
        alert_manager.alert_system_error(
            component='credentials',
            error_msg='\n'.join(issues)
        )

# 每天检查一次
scheduler.add_job(
    func=check_credentials_validity,
    trigger=CronTrigger(hour=9, minute=0)
)
```

### 6. 📊 **性能监控**（重要性：⭐⭐）

**现状问题：**

- ⚠️ 不知道系统资源使用情况
- ⚠️ 内存泄漏可能不被发现

**改进方案：**

```python
import psutil

def monitor_system_resources():
    """监控系统资源"""
    cpu_percent = psutil.cpu_percent(interval=1)
    memory = psutil.virtual_memory()

    logger.info(f"💻 CPU: {cpu_percent}% | 内存: {memory.percent}%")

    # 如果资源占用过高，告警
    if cpu_percent > 80:
        alert_manager.alert_system_error(
            component='cpu',
            error_msg=f'CPU占用过高: {cpu_percent}%'
        )

    if memory.percent > 85:
        alert_manager.alert_system_error(
            component='memory',
            error_msg=f'内存占用过高: {memory.percent}%'
        )

# 每小时监控一次
scheduler.add_job(
    func=monitor_system_resources,
    trigger='interval',
    hours=1
)
```

```python
def check_external_services():
    """检查外部服务可用性"""
    services = {
        'bifaw': 'https://www.bifaw.com',
        '500彩票': 'https://odds.500.com'
    }

    for name, url in services.items():
        try:
            response = requests.get(url, timeout=10)
            if response.status_code != 200:
                alert_manager.alert_system_error(
                    component=name,
                    error_msg=f'{name}返回状态码: {response.status_code}'
                )
        except Exception as e:
            alert_manager.alert_system_error(
                component=name,
                error_msg=f'{name}无法访问: {e}'
            )

# 每6小时检查一次
scheduler.add_job(
    func=check_external_services,
    trigger='interval',
    hours=6
)
```
