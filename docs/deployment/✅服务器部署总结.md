## 🚀 快速部署（3 步）

### 第 1 步：上传文件到服务器

```bash
# 在本地电脑
scp -r d:\MSM\Cursor\football root@your-server:/root/
```

或使用 FTP/SFTP 工具上传整个 `football` 目录到 `/root/`

---

### 第 2 步：运行部署脚本

```bash
# SSH登录服务器
ssh root@your-server

# 进入目录
cd /root/football

# 给脚本执行权限
chmod +x 服务器快速部署.sh

# 运行部署脚本
./服务器快速部署.sh

# 设置企业微信Webhook
export WECOM_WEBHOOK="https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
```

---

### 第 3 步：启动服务

#### 方式 A：前台运行（测试）

```bash
# 激活虚拟环境
source venv/bin/activate

# 启动服务
python app.py
```

**访问**: `http://your-server-ip:5002`

#### 方式 B：systemd 管理（推荐）

```bash
# 1. 修改服务配置中的Webhook
nano football.service
# 修改 WECOM_WEBHOOK 的值

# 2. 安装服务
sudo cp football.service /etc/systemd/system/
sudo systemctl daemon-reload

# 3. 启动服务
sudo systemctl start football

# 4. 开机自启
sudo systemctl enable football

# 5. 查看状态
sudo systemctl status football

# 6. 查看日志
sudo journalctl -u football -f
```

## 🔧 防火墙配置

### CentOS/RHEL


## ⚠️ 常见问题

### 1. 端口被占用

```bash
# 查看端口占用
sudo lsof -i:5002

# 或者
sudo netstat -tulpn | grep 5002

# 杀死进程
sudo kill -9 PID
```

### 2. 权限问题

```bash
# 给予执行权限
chmod +x /root/football/app.py
chmod +x /root/football/服务器快速部署.sh
```

### 3. Python 版本问题

```bash
# 检查Python版本（需要3.8+）
python3 --version

# 如果版本过低，升级Python
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install python3.9

# CentOS/RHEL
sudo yum install python39
```

### 4. Chrome/Selenium 问题

```bash
# 安装Chrome/Chromium
# Ubuntu/Debian
sudo apt-get install chromium-browser chromium-chromedriver

# CentOS/RHEL
sudo yum install chromium chromium-chromedriver
```
