## 🔍 策略 1（分级阈值）详情

### 动态阈值计算

```python
def _calculate_dynamic_threshold(self, metrics: Dict, funding_level: Dict) -> float:
    base_threshold = 0.80
    adjustments = 0

    # 1. 成交量调整
    if volume > 500000: adjustments -= 0.03  # 大热门降低
    elif volume < 50000: adjustments += 0.05  # 冷门提高

    # 2. 数据质量调整
    if data_quality == 3: adjustments -= 0.02  # 完整数据降低
    elif data_quality < 2: adjustments += 0.03  # 不完整提高

    # 3. 资金等级调整
    if sbre_weight >= 0.85: adjustments -= 0.02  # L1/L2降低
    elif sbre_weight <= 0.35: adjustments += 0.03  # L4/L5提高

    return max(0.70, min(0.90, base_threshold + adjustments))
```

### 效果

```
英超大热门: 阈值0.70-0.73 → 更多推荐
低级别冷门: 阈值0.85-0.90 → 更严格
```
