## ⚠️ 注意事项

### 1. JSON 文件要求

自动推送系统依赖 JSON 文件：

- 文件必须存在于 `data/YYYY/MM/DD/` 目录
- 文件名必须包含主队和客队名称
- 文件格式必须符合 X1 JSON 规范

### 2. 熔断处理

如果推荐熔断（数据不完整），会：

- 记录日志
- 跳过推送
- 继续处理下一场比赛
