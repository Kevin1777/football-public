## 🎯 核心功能

### 1️⃣ 自动记录推荐

```
生成推荐
    ↓
自动保存到数据库
    ↓
记录所有关键信息：
  - 比赛信息
  - 推荐方向
  - 置信度
  - 评分详情
  - 风控标记
```

**数据库**: `recommendation_tracker.db`

- ✅ recommendations 表 - 推荐记录
- ✅ daily_reviews 表 - 每日审查统计

### 2️⃣ 定时审查（每天中午 12 点）

```
定时触发
    ↓
扫描前一天的推荐
    ↓
从JSON文件名提取实际比分
    ↓
判断推荐正确性
    ↓
更新数据库
    ↓
生成可视化报告
    ↓
推送到企业微信
```

**准确率计算**:

- 整体准确率 = 正确数 / (正确数 + 错误数)
- 走盘不计入准确率统计

### 3️⃣ 可视化报告

**报告内容**:

- 🎨 评级卡片（优秀/良好/一般/需改进）
- 📊 统计卡片（6 个关键指标）
- 📈 准确率饼图
- 📉 7 天趋势图
- 📊 置信度对比柱状图
- 💡 分析总结

**报告保存**: `daily_reports/YYYYMMDD/report.html`

### 4️⃣ 企业微信推送

**推送内容**:

```markdown
## 📊 每日推荐审查报告

**日期**: 2025-11-25
**准确率**: 🟢 80.0%

### 📈 整体统计

- 推荐总数: 10
- 正确: ✅ 8
- 错误: ❌ 2

### 🎯 准确率

🟢 整体: 80.0%
🌟 高置信度: 85.0%

📄 详细报告: [点击查看]
```

### 5️⃣ REST API 接口

| 接口                      | 方法 | 说明                   |
| ------------------------- | ---- | ---------------------- |
| `/api/x1/recommend`       | POST | 单个推荐（自动记录）   |
| `/api/x1/batch_recommend` | POST | 批量推荐（自动记录）   |
| `/api/x1/stats`           | GET  | 统计信息（含实时数据） |
| `/api/x1/review/trigger`  | POST | 触发审查               |
| `/api/x1/review/history`  | GET  | 审查历史               |
| `/api/x1/review/pending`  | GET  | 待审查列表             |

## 💡 使用示例

### 自动记录

```python
# 生成推荐时自动记录
response = requests.post(
    "http://127.0.0.1:5002/api/x1/recommend",
    json={"json_path": "data/2025/11/25/比赛.json"}
)

# 返回包含record_id
result = response.json()
print(f"记录ID: {result['record_id']}")
```

### 触发审查

```python
# 手动触发审查
response = requests.post(
    "http://127.0.0.1:5002/api/x1/review/trigger",
    json={"date": "2025-11-25"}
)

result = response.json()
print(f"准确率: {result['result']['accuracy']:.1f}%")
print(f"报告: {result['result']['report_path']}")
```

### 查看历史

```python
# 查看7天历史
response = requests.get(
    "http://127.0.0.1:5002/api/x1/review/history?days=7"
)

reviews = response.json()['reviews']
for review in reviews:
    print(f"{review['review_date']}: {review['accuracy']:.1f}%")
```

## 🔍 监控指标

### 日常关注

1. **准确率趋势**

   - 是否保持稳定
   - 是否有下降趋势
   - 高置信度 vs 整体

2. **推荐质量**

   - 高置信度占比
   - 风控触发率
   - 熔断率

3. **联赛表现**
   - 哪些联赛准确率高
   - 哪些联赛需要优化

### 预警阈值

- ⚠️ 准确率 < 70% - 需要关注
- 🚨 准确率 < 65% - 需要调整策略
- ✅ 准确率 ≥ 80% - 表现优秀
