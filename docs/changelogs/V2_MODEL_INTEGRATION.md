## 🎯 V2 模型核心规则

基于 820 场历史数据训练的简单高效规则：

```python
# 主胜推荐
if 成交占比差 >= 30% and 必发指数差 >= 0 and 成交量 >= 50,000:
    推荐主胜
    置信度 = 0.70 + 各种加成（最高0.99）

# 客胜推荐
if 成交占比差 <= -30% and 必发指数差 <= 0 and 成交量 >= 50,000:
    推荐客胜
    置信度 = 0.70 + 各种加成（最高0.99）
```
