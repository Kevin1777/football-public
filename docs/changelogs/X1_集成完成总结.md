## 🎯 核心功能

### 1. REST API 接口

```
POST /api/x1/recommend          - 单个推荐
POST /api/x1/batch_recommend    - 批量推荐
GET  /api/x1/stats              - 统计信息
```

### 2. 推荐引擎

- ✅ FLM (热度前线) - 分析资金倾向
- ✅ SPM (结构承压) - 分析盘口赔率
- ✅ DPI (风险整合) - 综合评分
- ✅ SBRE 反解 - 诱导盘识别
- ✅ 四风控机制 - SmartSafe/SS-Dagger/LVC/TPI

```python

# 单个推荐
response = requests.post(
    "http://127.0.0.1:5002/api/x1/recommend",
    json={"json_path": "data/2025/11/25/比赛.json"}
)
result = response.json()

# 批量推荐
response = requests.post(
    "http://127.0.0.1:5002/api/x1/batch_recommend",
    json={"date": "2025-11-25", "min_confidence": 0.85}
)
result = response.json()

# 统计信息
response = requests.get("http://127.0.0.1:5002/api/x1/stats")
result = response.json()
```

## 🎓 与原系统的集成方式

### 推荐引擎架构

```
football项目
├── X1原版推荐引擎 (实时采集)
│   └── HandicapRecommendationEngineX1
│
├── X1 JSON推荐引擎 (JSON数据) ⭐ 新增
│   └── X1JSONRecommender
│   └── API: /api/x1/*
│
├── 优化推荐引擎 (盘口特征)
│   └── OptimizedRecommendationEngine
│
└── 规则推荐引擎 (比分反推)
    └── HybridRecommender
```

### 推荐流程

```
用户请求
  ↓
选择推荐引擎
  ├─→ 有JSON文件? → X1 JSON推荐 (优先) ✅
  ├─→ 无JSON文件? → X1原版实时采集
  └─→ 辅助验证 → 优化引擎 + 规则引擎
  ↓
返回推荐结果
```
