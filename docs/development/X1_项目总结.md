# X1 JSON 推荐模型 - 项目总结

## 📌 项目概述

基于《X1 本地部署版 · UG-only 修复母本（GROK4 适配版）》核心逻辑，设计并实现了一个**仅使用 JSON 数据**的足球比赛让球盘口推荐系统。

**核心目标**: 解构 X1 母本的复杂依赖（UG 图像、PDF、实时采集），转换为基于结构化 JSON 数据的离线推荐模型。

---

## ✅ 已完成工作

### 1. 核心推荐引擎 (`recommendation/x1_json_recommender.py`)

实现了完整的 X1 推荐逻辑，包括：

#### 📊 评分模块

- **FLM (Frontline Logic Module)** - 热度前线评分

  - 分析三方成交占比（主/和/客）
  - 识别资金倾向方向
  - 判断热度类型：强热支持/热度支持/热度均衡/虚热

- **SPM (Structure Pressure Module)** - 结构承压评分

  - 盘口变化分析（升盘/降盘）
  - 赔率水位变化分析
  - 结构类型判断：顺势结构/诱导结构/中性结构

- **DPI (Directional Pressure Integration)** - 风险整合评分
  - 综合 FLM 和 SPM 结果
  - 方向一致性判断
  - 风险等级评定：低风险/中风险/高风险

#### ⚠️ 风控机制

- **SmartSafe**: 结构支撑缺失检测
- **SS-Dagger**: 诱导盘识别
- **LVC**: 落点验证（凯利指数异常）
- **TPI**: 穿盘预警（深盘配低水）

#### 🔄 SBRE 反解机制

- 资金等级权重表 (L1~L5)
- L1/L2 高权重触发反向推荐
- 诱导盘自动反解

#### 🔥 熔断系统

- **F-GATE**: 数据门控（文件缺失）
- **F-EVD**: 数据校验（字段不完整）
- **F-CONS**: 风控熔断（多风控触发+高风险）
- **F-CAP**: 执行异常（程序错误）

## 🚀 使用方式

### 基础使用

```python
from recommendation.x1_json_recommender import X1JSONRecommender

recommender = X1JSONRecommender()
result = recommender.recommend("data/2025/11/25/比赛.json")

if result['recommendation']['direction'] != 'none':
    print(f"推荐: {result['recommendation']['handicap']}")
    print(f"置信度: {result['recommendation']['confidence_pct']}")
```

### 批量测试

```bash

```

### 集成到系统

```python
# 在 app.py 中添加路由
@app.route('/api/x1_recommend', methods=['POST'])
def x1_recommend():
    json_path = request.json.get('json_path')
    result = x1_recommender.recommend(json_path)
    return jsonify(result)
```

## 🔧 技术亮点

### 1. 智能数据提取

自动从 JSON 中提取 40+个指标：

- 成交量、占比、盘口、赔率
- 必发指数、凯利指数、赔付率
- 欧赔、热指、赔指等

### 2. 多层风控体系

```
数据完整性检查 (F-GATE/F-EVD)
    ↓
基础评分 (FLM/SPM/DPI)
    ↓
风控检测 (SmartSafe/SS-Dagger/LVC/TPI)
    ↓
SBRE反解 (资金等级加权)
    ↓
最终推荐 / 熔断
```

### 3. 置信度计算

```python
# FLM + SPM 一致性加权
if flm_direction == spm_direction:
    confidence = (flm_conf + spm_conf) / 2 * 1.2  # 提升20%
else:
    confidence = max(flm_conf, spm_conf) * 0.7   # 降低30%

# SBRE反解权重
if sbre_triggered:
    final_confidence = sbre_weight * base_confidence
```

## 🎓 X1 母本核心理念的实现

### 1. 三权分立（X1 原则）

| 维度         | X1 母本                  | JSON 版本                   |
| ------------ | ------------------------ | --------------------------- |
| **盘口维**   | UG 盘口图（主权威）      | handicap_data（500 彩票网） |
| **资金维**   | Betfair 资金图（主权威） | trade_data 三方占比         |
| **动力学维** | UG-PDF 成交明细          | trade_data 逐笔数据         |

✅ **实现**: 三个维度数据独立提取，互相验证

### 2. 全程侦破（X1 理念）

X1 母本强调：

JSON 版本实现：


### 3. 风控优先（X1 原则）

> 任意风控触发 + 高风险 → 立即熔断

JSON 版本实现：

```python
if any(risk_flags.values()) and dpi['risk_level'] == '高风险':
    return meltdown_result('F-CONS', '风控机制触发')
```
