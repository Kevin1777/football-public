## 💰 盈亏计算

### 5 种结果类型

| 结果              | 盈亏（1 单位，水位 0.90） |
| ----------------- | ------------------------- |
| 全赢（WIN）       | +0.90                     |
| 半赢（HALF_WIN）  | +0.45                     |
| 走水（DRAW）      | 0.00                      |
| 半输（HALF_LOSE） | -0.50                     |
| 全输（LOSE）      | -1.00                     |

### 计算逻辑

**推荐"客队受让 0.5"，实际比分 2:1**

```
客队得分 + 让球数 vs 主队得分
1 + 0.5 = 1.5 vs 2
1.5 < 2 → 全输
盈亏：-1.00
```

## 📈 统计指标

### 胜率

```
胜率 = (全赢 + 半赢×0.5) / 推荐总数 × 100%
```

### ROI（投资回报率）

```
ROI = 总盈亏 / 总投入 × 100%
```
