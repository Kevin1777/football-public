# 推荐引擎修复说明

## 🐛 问题描述

用户遇到错误：

```
推荐生成失败：交易明细解析失败: 解析失败：未能从网页表格中识别有效数据
```

## 🔍 问题原因

推荐引擎 API (`/api/recommendation/generate`) 在获取交易明细时，使用了错误的方法：

- ❌ 原来：尝试调用不存在的 `bifaw_client.get_match_detail()` 方法
- ❌ 后来：直接使用 `fetch_match_detail_response()` + 手动解析
- ⚠️ 问题：没有使用 Selenium 抓取，容易遇到反爬或格式问题

## ✅ 修复方案

修改推荐引擎 API，使用与 `/api/bifaw/match_detail` **完全相同**的方法获取明细：

### 修改内容

```python
# 使用Selenium抓取明细（默认方式，更可靠）
html = bifaw_client.fetch_match_detail_selenium(
    detail_url=detail_url,
    match=match_info if isinstance(match_info, dict) else None,
    detail_params=detail_params if isinstance(detail_params, dict) else None,
)

# 解析HTML获取DataFrame
trade_data = parse_bifa_html(html, match=match_info if isinstance(match_info, dict) else None)

# 检查解析结果
if not isinstance(trade_data, pd.DataFrame) or trade_data.empty:
    error_msg = trade_data if isinstance(trade_data, str) else "未解析到明细数据"
    return jsonify({
        "success": False,
        "message": f"交易明细解析失败: {error_msg}"
    }), 500
```

### 优势

1. ✅ **使用 Selenium** - 更稳定，可以处理动态加载的内容
2. ✅ **自动截图** - 出问题时可以查看 debug 目录的截图
3. ✅ **与现有 API 一致** - 复用已验证可行的逻辑
4. ✅ **更好的错误处理** - 提供详细的错误信息

## 📋 可能的错误及解决

### 1. "交易明细解析失败"

**原因**：Cookie 过期或页面格式变化
**解决**：

- 重新登录系统
- 查看 debug 目录的截图确认页面内容

### 2. "让球盘口数据获取失败"

**原因**：500 彩票网没有该比赛数据
**解决**：

- 确认球队名称准确
- 确认比赛日期正确
- 该比赛可能没有让球盘口

### 3. "不推荐下注"

**原因**：推荐引擎评估风险过高
**说明**：

- 这是正常的风控机制
- 系统会在日志中说明原因
- 置信度低于阈值或风险等级过高时会触发
