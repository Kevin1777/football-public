# 完场比赛盘口获取优化

## 🎯 问题

**完场比赛无法获取盘口数据：**

```
未找到任何匹配: 墨西哥美洲 vs 莱昂
未找到比赛: 托卢卡 vs 墨西哥美洲
```

## 🔍 原因分析

### 1. URL 可能不同

500 彩票网可能对完场比赛使用不同的页面：

- **未来/当天比赛**：`https://odds.500.com/fenxi/shuju-{date}.shtml`
- **完场比赛**：可能在其他位置或格式

### 2. 球队名称翻译差异

必发指数网 vs 500 彩票网：

- `墨西哥美洲` vs `美洲`？
- `莱昂` vs `里昂`？
- `托卢卡` vs `托卢卡`？

### 3. 页面结构可能不同

完场比赛页面的 HTML 结构可能与未来比赛不同。

### 3. 增强模糊匹配

**新增功能：**

#### a) 双向匹配

```python
# 正向：target在text中
if target in text:
    return True

# 反向：text在target中（处理简称）
if text in target:
    return True
```

#### b) 更多城市前缀

```python
prefixes = [
    '墨西哥', '阿根廷', '巴西',
    '新墨西哥', '洛杉矶', '纽约',
    '圣保罗', '里约热内卢', ...
]
```

#### c) 核心队名匹配

```python
# 取后2-4个字作为核心
for length in [4, 3, 2]:
    core_name = target[-length:]
    if core_name in text:
        return True
```

#### d) 双字匹配（最宽松）

```python
# 任意连续2个字匹配
for i in range(len(target) - 1):
    bi_gram = target[i:i+2]
    if bi_gram in text:
        return True
```
