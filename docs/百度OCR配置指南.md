# 百度 OCR 自动识别配置指南 🔍

## 📌 功能说明

百度 OCR 用于自动识别必发网登录页面的验证码，实现全自动登录功能。配置后，系统可以：

- ✅ 自动识别 4 位数字/字母验证码
- ✅ 自动填写并提交登录表单
- ✅ 大幅提升采集效率（无需人工干预）

---

## 1️⃣ 申请百度 OCR API

### 步骤 1: 注册百度智能云账号

访问 [百度智能云](https://cloud.baidu.com/) 并注册/登录账号

### 步骤 2: 进入 OCR 控制台

1. 登录后，点击顶部导航 **产品服务**
2. 选择 **人工智能** → **文字识别 OCR**
3. 或直接访问：https://console.bce.baidu.com/ai/#/ai/ocr/overview/index

### 步骤 3: 创建应用

1. 点击 **"创建应用"** 按钮
2. 填写应用信息：
   - **应用名称**：`必发网验证码识别` （或其他名称）
   - **接口选择**：勾选 **通用文字识别（标准版）**
   - **文字识别包名**：留空或填写你的项目名
   - **应用归属**：个人
   - **应用描述**：可选填写

### 步骤 4: 获取 API 密钥

创建成功后，在应用列表中找到你的应用，查看并复制：

- **API Key**：一串 32 位字符
- **Secret Key**：一串 32 位字符

> 💡 **免费额度**：百度 OCR 每月有一定免费调用次数（通常足够个人使用）

## 2️⃣ 配置环境变量

### 方法 A：使用 `.env` 文件（推荐）

1. **复制示例文件**

   ```bash
   cd d:\MSM\Cursor\football
   copy .env.example .env
   ```

2. **编辑 `.env` 文件**

   ```bash
   # 打开.env文件，填写你的API密钥
   notepad .env
   ```

3. **填写配置**（替换为你的实际密钥）：

   ```bash
   # 百度OCR配置
   BAIDU_OCR_ENABLED=1

   # 从百度智能云控制台获取的密钥
   BAIDU_OCR_API_KEY=你的API_Key
   BAIDU_OCR_SECRET_KEY=你的Secret_Key
   ```

4. **保存文件**

### 方法 B：使用系统环境变量（Windows）

如果不想创建 `.env` 文件，可以设置系统环境变量：

1. **打开环境变量设置**

   - 按 `Win + R`，输入 `sysdm.cpl`，回车
   - 点击 **"高级"** 标签 → **"环境变量"**

2. **添加用户变量**

   - 点击 **"新建"**，依次添加：

     ```
     变量名：BAIDU_OCR_ENABLED
     变量值：1

     变量名：BAIDU_OCR_API_KEY
     变量值：你的API_Key

     变量名：BAIDU_OCR_SECRET_KEY
     变量值：你的Secret_Key
     ```

3. **重启终端/IDE** 使环境变量生效

## 🔧 故障排除

### 问题 1: "百度 OCR 未配置 API 密钥"

**原因**：未正确配置环境变量

**解决方案**：

1. 检查 `.env` 文件是否存在于项目根目录
2. 检查变量名是否正确（注意大小写）
3. 检查 API 密钥是否有多余的空格或引号
4. 重启 IDE/终端

### 问题 2: "获取 Access Token 失败"

**原因**：API 密钥错误或网络问题

**解决方案**：

1. 登录百度智能云控制台，重新检查 API 密钥
2. 确认网络可以访问百度 API
3. 检查是否超出免费额度

### 问题 3: "OCR 识别失败"

**原因**：验证码图片质量差或 OCR 误识别

**解决方案**：

1. 查看保存的验证码图片（`debug_html/captcha_*.png`）
2. 如果图片模糊，可能是网络问题，重试即可
3. 如果识别错误，系统会自动重试

### 问题 4: "识别结果为空"

**原因**：验证码图片异常

**解决方案**：

1. 检查验证码图片是否正常下载
2. 尝试手动登录一次，让系统重新获取 cookies
3. 增加重试次数

## ❓ 常见问题

**Q: 免费额度用完了怎么办？**  
A: 可以购买百度 OCR 的付费套餐，或者暂时禁用 OCR（设置 `BAIDU_OCR_ENABLED=0`），改用手动输入验证码。

**Q: 可以用其他 OCR 服务吗？**  
A: 可以，代码支持扩展其他 OCR 服务。参考 `services/baidu_ocr.py` 实现接口即可。

**Q: OCR 识别速度如何？**  
A: 通常 1-2 秒完成识别，网络状况良好时可达毫秒级。

**Q: 识别准确率多少？**  
A: 对于 4 位数字/字母验证码，准确率约 95%。系统会自动重试识别失败的情况。
