## 🔥 Python 脚本调用

创建 `my_test.py`:

```python
from recommendation.x1_json_recommender import X1JSONRecommender

recommender = X1JSONRecommender()

# 测试一场比赛
result = recommender.recommend(
    "data/2025/11/25/2025-11-25_欧联U19_曼彻斯特城U19_vs_勒沃库森U19_2300.json"
)

# 提取关键信息
rec = result['recommendation']

if rec['direction'] != 'none':
    print(f"✅ 推荐: {rec['handicap']}")
    print(f"📊 置信度: {rec['confidence_pct']}")
    print(f"💡 理由: {rec['reason']}")
else:
    print(f"❌ 不推荐: {result.get('meltdown', {}).get('reason', '未知')}")
```

运行：

```bash
python my_test.py
```

## 🎯 过滤高置信度推荐

```python
from pathlib import Path
from recommendation.x1_json_recommender import X1JSONRecommender

recommender = X1JSONRecommender()

# 扫描某个日期
data_dir = Path("data/2025/11/25")
high_confidence_recs = []

for json_file in data_dir.glob("2025-*.json"):
    result = recommender.recommend(str(json_file))
    rec = result.get('recommendation', {})

    # 只保留高置信度推荐
    if rec.get('confidence', 0) >= 0.85 and rec.get('direction') != 'none':
        high_confidence_recs.append({
            'file': json_file.name,
            'match': result['match_info'],
            'recommendation': rec
        })

# 打印结果
print(f"找到 {len(high_confidence_recs)} 个高置信度推荐:")
for item in high_confidence_recs:
    match = item['match']
    rec = item['recommendation']
    print(f"\n{match['home']} vs {match['away']}")
    print(f"  推荐: {rec['handicap']}")
    print(f"  置信度: {rec['confidence_pct']}")
```

## 📈 对比实际结果（回测）

```python
# 假设你有历史比赛的实际比分
actual_scores = {
    "2025-11-25_欧联U19_曼彻斯特城U19_vs_勒沃库森U19_2300.json": {"home": 2, "away": 0},
    # ... 更多比赛
}

from recommendation.x1_json_recommender import X1JSONRecommender

recommender = X1JSONRecommender()
correct = 0
total = 0

for json_file, score in actual_scores.items():
    result = recommender.recommend(f"data/2025/11/25/{json_file}")
    rec = result.get('recommendation', {})

    if rec.get('direction') == 'none':
        continue

    total += 1

    # 判断推荐是否正确
    if rec['direction'] == 'home' and score['home'] > score['away']:
        correct += 1
    elif rec['direction'] == 'away' and score['away'] > score['home']:
        correct += 1

accuracy = correct / total * 100 if total > 0 else 0
print(f"准确率: {accuracy:.1f}% ({correct}/{total})")
```

## ⚠️ 常见问题

### Q1: 找不到 JSON 文件？

**A**: 检查路径是否正确，确保文件在 `data/年/月/日/` 目录下。

### Q2: 总是返回熔断？

**A**: 检查 JSON 文件是否包含必要字段：

- `match_info`
- `handicap_data` (包含 `current_handicap`, `initial_handicap`)
- `trade_data` (包含 `data` 数组)

### Q3: 置信度都很低？

**A**: 可能是数据质量问题：

- 成交量太小（< 10,000）
- 盘口变化不明显
- 三方占比接近（没有明显倾向）

### Q4: 如何提高准确率？

**A**:

1. 只跟高置信度推荐 (>= 0.85)
2. 避开风控触发的比赛
3. 关注资金等级 L2/L3 及以上的比赛
