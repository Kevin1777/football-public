## 🎯 3 分钟快速配置

### 步骤 1：配置告警 Webhook

编辑 `.env` 文件，添加：

```bash
# 告警专用Webhook（推荐单独配置）
WECOM_ALERT_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx

# 如果没有单独配置，系统会使用推送的Webhook
# 也可以两者使用同一个
```

**获取 Webhook 方法：**

1. 打开企业微信群聊
2. 点击右上角 `...` → 群机器人 → 添加机器人
3. 复制 Webhook 地址

### 步骤 2：测试配置

## 📝 查看日志

### 通过 API 查看

```bash
# 查看最近500行日志
curl http://localhost:5000/api/logs/view?lines=500

# 搜索日志
curl -X POST http://localhost:5000/api/logs/search \
  -H "Content-Type: application/json" \
  -d '{"keyword": "告警", "max_results": 50}'

# 获取日志统计
curl http://localhost:5000/api/logs/stats
```

### 直接查看文件

```bash
# Windows
type logs\football_current.log | more

tail -f logs/football_current.log
```

## ⚠️ 常见问题

### Q1: 没有收到告警消息？

检查：

1. `.env` 中是否配置了 `WECOM_ALERT_WEBHOOK`
2. Webhook 地址是否正确
3. 查看日志中是否有"告警系统已启用"

### Q2: 告警太频繁？

- 默认冷却期 30 分钟（同类告警）
- 可在 `utils/alert_manager.py` 中调整 `cooldown_minutes`

### Q3: 健康检查报错？

- 确保 `data/` 和 `logs/` 目录存在
- 查看具体错误信息，调整阈值

### Q4: 想测试告警功能？

```bash
python test_optimization.py
```
