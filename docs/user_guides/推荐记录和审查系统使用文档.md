# 推荐记录和审查系统 - 使用文档

## 📋 概述

完整的推荐追踪和准确率审查系统，自动记录每次推荐，定时审查准确率，并生成可视化报告。

### 核心功能

1. ✅ **自动记录推荐** - 每次生成推荐时自动保存到数据库
2. ✅ **定时审查** - 每天中午 12 点自动审查前一天的推荐
3. ✅ **可视化报告** - 生成包含图表的 HTML 报告
4. ✅ **企业微信推送** - 自动推送审查结果
5. ✅ **历史统计** - 查看累计准确率和趋势

## 📡 API 接口

### 1. 单个推荐（自动记录）

```bash
POST http://127.0.0.1:5002/api/x1/recommend
```

**请求**:

```json
{
  "json_path": "data/2025/11/25/比赛.json"
}
```

**响应**:

```json
{
  "success": true,
  "record_id": 123, // 🔥 记录ID
  "recommendation": {
    "direction": "home",
    "handicap": "主队 球半 @0.8",
    "confidence": 0.85
  }
}
```

## 🗄️ 数据库结构

### recommendations 表

存储每次推荐的详细信息：

| 字段              | 类型    | 说明         |
| ----------------- | ------- | ------------ |
| id                | INTEGER | 主键         |
| recommend_time    | TEXT    | 推荐时间     |
| match_date        | TEXT    | 比赛日期     |
| home_team         | TEXT    | 主队         |
| away_team         | TEXT    | 客队         |
| recommendation    | TEXT    | 推荐方向     |
| confidence        | REAL    | 置信度       |
| confidence_level  | TEXT    | 置信度等级   |
| funding_level     | TEXT    | 资金等级     |
| flm_level         | TEXT    | FLM 等级     |
| spm_structure     | TEXT    | SPM 结构     |
| dpi_risk          | TEXT    | DPI 风险     |
| risk_flags        | TEXT    | 风控标记     |
| actual_home_score | INTEGER | 实际主队得分 |
| actual_away_score | INTEGER | 实际客队得分 |
| is_correct        | INTEGER | 是否正确     |
| reviewed          | INTEGER | 是否已审查   |

### daily_reviews 表

存储每日审查统计：

| 字段                     | 类型    | 说明           |
| ------------------------ | ------- | -------------- |
| id                       | INTEGER | 主键           |
| review_date              | TEXT    | 审查日期       |
| total_recommendations    | INTEGER | 推荐总数       |
| reviewed                 | INTEGER | 已审查数       |
| correct                  | INTEGER | 正确数         |
| wrong                    | INTEGER | 错误数         |
| accuracy                 | REAL    | 准确率         |
| high_confidence_accuracy | REAL    | 高置信度准确率 |
| report_path              | TEXT    | 报告路径       |

## 💡 使用场景

### 场景 1: 查看今天的推荐效果

```python
import requests

# 触发审查
response = requests.post(
    "http://127.0.0.1:5002/api/x1/review/trigger",
    json={"date": "2025-11-25"}
)

result = response.json()
if result['success']:
    print(f"准确率: {result['result']['accuracy']:.1f}%")
    print(f"正确: {result['result']['correct']}")
    print(f"错误: {result['result']['wrong']}")
```

### 场景 2: 查看 7 天准确率趋势

```python
# 获取历史
response = requests.get(
    "http://127.0.0.1:5002/api/x1/review/history?days=7"
)

reviews = response.json()['reviews']
for review in reviews:
    print(f"{review['review_date']}: {review['accuracy']:.1f}%")
```

### 场景 3: 查看待审查的推荐

```python
# 获取待审查列表
response = requests.get(
    "http://127.0.0.1:5002/api/x1/review/pending"
)

pending = response.json()['pending']
print(f"待审查: {len(pending)}条")
for rec in pending:
    print(f"{rec['home_team']} vs {rec['away_team']}: {rec['recommendation']}")
```

## 📈 数据分析示例

### 计算周准确率

```python
from recommendation_tracker import tracker
from datetime import datetime, timedelta

# 获取本周数据
reviews = tracker.get_recent_reviews(7)
weekly_correct = sum(r['correct'] for r in reviews)
weekly_wrong = sum(r['wrong'] for r in reviews)
weekly_accuracy = weekly_correct / (weekly_correct + weekly_wrong) * 100

print(f"本周准确率: {weekly_accuracy:.1f}%")
```

### 按联赛统计

```python
import sqlite3

conn = sqlite3.connect("recommendation_tracker.db")
cursor = conn.cursor()

cursor.execute("""
    SELECT league,
           COUNT(*) as total,
           SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) as correct
    FROM recommendations
    WHERE reviewed = 1
    GROUP BY league
    ORDER BY total DESC
    LIMIT 10
""")

for row in cursor.fetchall():
    league, total, correct = row
    accuracy = correct / total * 100 if total > 0 else 0
    print(f"{league}: {accuracy:.1f}% ({total}场)")
```

## ⚠️ 注意事项

### 1. 数据库备份

定期备份 `recommendation_tracker.db`:

```bash
cp recommendation_tracker.db recommendation_tracker_backup_$(date +%Y%m%d).db
```

### 2. 报告清理

定期清理旧报告：

```bash
# 删除30天前的报告
find daily_reports -type d -mtime +30 -exec rm -rf {} \;
```

### 3. 比分提取

系统自动从 JSON 文件名提取比分，文件名格式必须为：

```
2025-11-25_联赛_主队_vs_客队_主队得分_客队得分_时间.json
```

### 4. 走盘处理

走盘（平局）不计入准确率统计，但会记录在报告中。
