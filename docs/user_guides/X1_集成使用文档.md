#### Python 调用示例

```python
import requests

    "date": "2025-11-25",
    "min_confidence": 0.85
}

if result['success']:
    print(f"找到 {result['total']} 个高置信度推荐")
    for item in result['recommendations']:
        rec = item['recommendation']
        print(f"{item['match']}: {rec['handicap']} ({rec['confidence_pct']})")
```

## 💡 使用场景

### 场景 1: 单个比赛推荐

```python
# 获取某场比赛的推荐
json_path = "data/2025/11/25/2025-11-25_欧联U19_曼彻斯特城U19_vs_勒沃库森U19_2300.json"
result = requests.post(
    "http://127.0.0.1:5002/api/x1/recommend",
    json={"json_path": json_path}
).json()

if result['success'] and result['recommendation']['confidence'] >= 0.85:
    print(f"✅ 高置信度推荐: {result['recommendation']['handicap']}")
```

### 场景 2: 每日高置信度推荐

```python

result = requests.post(
    "http://127.0.0.1:5002/api/x1/batch_recommend",
```

## 🎯 推荐策略

### 保守策略（推荐）⭐⭐⭐⭐⭐

```python
min_confidence = 0.85
risk_control_filter = True

result = requests.post(
    "http://127.0.0.1:5002/api/x1/batch_recommend",
    json={"date": "2025-11-25", "min_confidence": min_confidence}
).json()

# 过滤风控触发的比赛
safe_recommendations = []
for item in result['recommendations']:
    risk_flags = item['risk_control']
    # 排除LVC和TPI触发的比赛
    if not risk_flags['LVC'] and not risk_flags['TPI']:
        safe_recommendations.append(item)

print(f"安全推荐: {len(safe_recommendations)}个")
```

### 极保守策略（最安全）⭐⭐⭐⭐⭐

```python
# 只跟随置信度≥0.90 + FLM强热 + 无风控的比赛
for item in result['recommendations']:
```

## 📊 与原有推荐系统的关系

### 推荐引擎对比

| 引擎        | 数据源    | 准确率           | 特点               | 使用场景  |
| ----------- | --------- | ---------------- | ------------------ | --------- |
| **X1 JSON** | JSON 文件 | 83.6% (高置信度) | 离线分析，快速响应 | ✅ 主推荐 |
| X1 原版     | 实时采集  | -                | 完整数据，需要采集 | 实时推荐  |
| 优化引擎    | 盘口特征  | -                | 基于 820 场分析    | 辅助参考  |
| 规则引擎    | 比分反推  | -                | 规则库             | 辅助验证  |

### 推荐使用方式

```
1. 优先使用 X1 JSON推荐 (准确率最高)
   ↓
2. 如果JSON不存在，使用X1原版实时采集
   ↓
3. 结合优化引擎和规则引擎进行验证
```

## ⚠️ 注意事项

### 1. 数据要求

- ✅ JSON 文件必须包含完整的成交明细和盘口数据
- ✅ 文件路径格式: `data/YYYY/MM/DD/比赛文件.json`
- ⚠️ 缺少数据会导致熔断

### 2. 置信度解读

| 置信度    | 准确率 | 建议     |
| --------- | ------ | -------- |
| ≥ 0.90    | ~85%+  | 强烈推荐 |
| 0.85-0.90 | ~83.6% | 推荐     |
| 0.70-0.85 | ~74.5% | 谨慎参考 |
| < 0.70    | 低     | 不建议   |

### 3. 风控信号

- 🚨 **LVC 触发**: 凯利指数异常，谨慎
- 🚨 **TPI 触发**: 穿盘预警，谨慎
- 🚨 **SS-Dagger 触发**: 诱导盘，可能反向
- 🚨 **SmartSafe 触发**: 结构矛盾，危险

## 🔧 扩展开发

### 自定义过滤器

```python
def filter_recommendations(recommendations, filters):
    """
    自定义过滤推荐

    filters = {
        'min_confidence': 0.85,
        'leagues': ['欧冠杯', '西甲'],
        'max_risk_flags': 0,
        'flm_level': '强热支持'
    }
    """
    filtered = []

    for item in recommendations:
        # 置信度过滤
        if item['recommendation']['confidence'] < filters.get('min_confidence', 0):
            continue

        # 联赛过滤
        if filters.get('leagues') and item['league'] not in filters['leagues']:
            continue

        # 风控过滤
        risk_count = sum([
            item['risk_control']['LVC'],
            item['risk_control']['TPI'],
            item['risk_control']['SmartSafe'],
            item['risk_control']['SS-Dagger']
        ])
        if risk_count > filters.get('max_risk_flags', 999):
            continue

        # FLM等级过滤
        if filters.get('flm_level') and item['scores']['FLM']['level'] != filters['flm_level']:
            continue

        filtered.append(item)

    return filtered
```
