### 2. 获取单场比赛盘口（最简单的方式）

**Python 示例**:

```python
import requests

response = requests.post(
    "http://127.0.0.1:5001/api/handicap/match",
    json={
        "home_team": "曼联",
        "away_team": "利物浦",
        "match_date": "2025-11-18"  # 可选
    }
)

result = response.json()
if result["success"]:
    data = result["data"]
    print(f"即时盘: {data['current_handicap_str']} ({data['current_handicap']})")
    print(f"水位: {data['current_home_odds']} / {data['current_away_odds']}")
```

**curl 示例**:

```bash
curl -X POST http://127.0.0.1:5001/api/handicap/match \
  -H "Content-Type: application/json" \
  -d "{\"home_team\":\"曼联\",\"away_team\":\"利物浦\"}"
```

### 3. 批量获取多场比赛

```python
import requests

response = requests.post(
    "http://127.0.0.1:5001/api/handicap/batch",
    json={
        "matches": [
            {"home_team": "曼联", "away_team": "利物浦"},
            {"home_team": "切尔西", "away_team": "阿森纳"}
        ]
    }
)

result = response.json()
print(f"成功: {result['success_count']}, 失败: {result['error_count']}")
```

## 📊 盘口数值说明

### 快速对照表

| 显示    | 数值  | 含义                                 |
| ------- | ----- | ------------------------------------ |
| 球半    | 1.5   | 主队让客队 1.5 球                    |
| 平手    | 0.0   | 不让球                               |
| 受半球  | -0.5  | 主队受让 0.5 球（客队让主队 0.5 球） |
| 受平/半 | -0.25 | 主队受让 0.25 球                     |

### 关键规则

- **正数** = 主队让球（主队强）
- **负数** = 主队受让（客队强）
- **"受"字** = 受让方，数值为负

## 🔧 API 端点速查

### 一站式获取（推荐）

```
POST /api/handicap/match
```

输入球队名称，自动搜索并获取盘口。

### 批量获取

```
POST /api/handicap/batch
```

一次获取多场比赛盘口。

### 搜索比赛 ID

```
POST /api/handicap/search
```

仅搜索，返回 500 彩票网的比赛 ID。

### 获取盘口数据

```
POST /api/handicap/data
```

根据已知的比赛 ID 获取盘口。

## 💡 使用技巧

### 1. 球队名称匹配

✅ **推荐**:

- 使用简短常用名称：`曼联`、`利物浦`

## 🔗 与现有功能集成

### 与必发比赛列表集成

```python
# 1. 获取必发比赛列表
matches_response = requests.get("http://127.0.0.1:5001/api/bifaw/matches")
matches = matches_response.json()["matches"]

# 2. 为每场比赛获取让球盘口
for match in matches:
    handicap_response = requests.post(
        "http://127.0.0.1:5001/api/handicap/match",
        json={
            "home_team": match["home"],
            "away_team": match["away"]
        }
    )

    if handicap_response.json()["success"]:
        handicap = handicap_response.json()["data"]["current_handicap"]
        print(f"{match['home']} vs {match['away']}: {handicap}")
```

## 🐛 常见问题

**Q: 提示"未找到比赛"怎么办？**

A:

1. 检查球队名称是否正确（尝试简化）
2. 确认比赛日期
3. 查看生成的`debug_500_search_*.html`文件

**Q: 如何理解负数盘口？**

A: 负数表示主队受让：

- `-0.5` = 主队受让半球 = 客队让主队半球
- `+1.5` = 主队让客队球半

**Q: 返回的水位怎么理解？**

A: 水位是博彩公司的赔率调整，通常在 0.80-1.00 之间。

- 水位高 = 该方向被看好程度低
- 水位低 = 该方向被看好程度高
