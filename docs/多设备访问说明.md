# 📱 多设备访问说明

## 🎯 使用场景

**在 tmux 中运行采集任务，从其他设备（手机/平板）查看进度**

## ✨ 工作原理

### 智能检测机制

页面加载时会自动检测采集状态：

```
访问页面
    ↓
检查是否有采集任务正在运行？
    ↓
    ├─ 有任务运行 → 进入查看模式（不登录）
    │   ├─ 显示"检测到采集任务正在运行"
    │   ├─ 加载历史日志
    │   └─ 实时同步采集进度
    │
    └─ 无任务运行 → 正常模式（自动登录）
        ├─ 尝试OCR自动登录
        └─ 可以开始新的采集
```

## 📖 使用步骤

### 服务器端（tmux）

```bash
# 1. 启动tmux会话
tmux new -s football

# 2. 启动Flask服务
cd /path/to/football
python app.py

# 3. 分离tmux会话（保持后台运行）
# 按 Ctrl+B，然后按 D
```

### 手机端访问

1. **打开浏览器**

   ```
   http://服务器IP:5001
   ```

2. **自动进入查看模式**

   ```
   📊 检测到采集任务正在运行，进入查看模式...
   📝 当前会话: session_20251121_120000
   💡 你可以在实时日志中查看采集进度，不会干扰服务器端任务
   ```

3. **查看历史日志**

   - 页面会自动加载历史日志
   - 显示所有采集进度和状态

4. **实时同步**
   - 如果任务还在运行，会实时显示新日志
   - 不会触发新的登录流程

## 🔧 技术细节

### 查看模式 vs 正常模式

| 特性       | 查看模式          | 正常模式   |
| ---------- | ----------------- | ---------- |
| 触发条件   | 有采集任务运行    | 无采集任务 |
| 自动登录   | ❌ 跳过           | ✅ 执行    |
| 历史日志   | ✅ 加载           | ✅ 加载    |
| 开始采集   | ⚠️ 提示任务运行中 | ✅ 允许    |
| 干扰服务器 | ❌ 不干扰         | N/A        |

### API 检查流程

```javascript
// 页面加载时
const statusResp = await fetch("/api/collect/status");
const statusData = await statusResp.json();

if (statusData.is_collecting && statusData.active_session) {
  // 进入查看模式
  appendLog("📊 检测到采集任务正在运行，进入查看模式...");
  return; // 跳过自动登录
}

// 否则执行正常登录流程
```

## 💡 常见问题

### Q1: 为什么手机访问会触发登录？

**之前的行为**:

- 每次访问页面都会自动执行 OCR 登录
- 即使服务器端已经在运行任务

**现在的行为**:

- 检测到有任务运行时，跳过登录
- 只加载历史日志，不干扰服务器

### Q2: 如何确认是否在查看模式？

**查看日志提示**:

```
📊 检测到采集任务正在运行，进入查看模式...
📝 当前会话: session_20251121_120000
💡 你可以在实时日志中查看采集进度，不会干扰服务器端任务
```

### Q3: 查看模式下能做什么？

**可以做**:

- ✅ 查看历史日志
- ✅ 查看实时采集进度
- ✅ 查看当前会话信息
- ✅ 查看数据统计

**不能做**:

- ❌ 开始新的采集（会提示任务运行中）
- ❌ 触发登录流程（避免干扰）

### Q4: 服务器端任务完成后？

任务完成后：

1. 刷新页面
2. 自动检测到无任务运行
3. 切换到正常模式
4. 可以开始新的采集

## 🔐 安全性

### 登录状态共享

- **服务器端登录** → 所有设备共享
- **Cookie 存储** → 服务器端保存
- **无需每次登录** → 查看模式不触发登录

### 并发保护

- **采集任务互斥** → 同一时间只能有一个任务
- **锁机制** → 防止冲突
- **状态检查** → 自动检测运行状态

## 🚀 最佳实践

### ✅ 推荐做法

1. **服务器端运行长时间任务**

   ```bash
   tmux new -s football
   python app.py
   # Ctrl+B, D 分离会话
   ```

2. **手机端随时查看**

   - 打开浏览器访问

### ⚠️ 注意事项

1. **不要同时启动多个采集**

   - 系统会自动拒绝
   - 显示冲突提示

2. **查看模式下不要强制登录**

   - 可能干扰服务器端任务
   - 导致 Cookie 冲突

3. **网络稳定性**
   - 确保设备能访问服务器
   - 使用稳定的网络连接
