# 匹配策略优化 - 时间优先版

## 💡 用户洞察

> "主要是比赛时间这个很少有差异的，联赛和队伍名字可能会有翻译的差异"

**完全正确！** 基于此洞察优化了匹配策略。

## 🎯 新的匹配策略

### 优先级排序

```
1️⃣ 时间匹配（最可靠）
    ↓
2️⃣ 球队名称模糊匹配（允许翻译差异）
    ↓
3️⃣ 联赛名称辅助（加分项，不强制）
```

## 📊 评分体系（v2.0）

### 必要条件

```
双方球队都匹配: 100分
```

**说明**：这是最低要求，至少双方球队名称要能匹配上（模糊匹配也算）

### 加分项

| 项目             | 分数 | 说明                   |
| ---------------- | ---- | ---------------------- |
| 主队名称完全匹配 | +30  | 说明翻译一致           |
| 客队名称完全匹配 | +30  | 说明翻译一致           |
| 联赛名称匹配     | +20  | 辅助验证，权重降低     |
| 联赛名称不匹配   | 0    | 不减分（可能翻译不同） |

### 最高分

```
100 + 30 + 30 + 20 = 180分
```

## 🔍 匹配流程

### 步骤 1：按日期获取页面

```
输入：2025-11-02
访问：https://odds.500.com/fenxi/shuju-20251102.shtml
```

### 步骤 2：查找候选比赛

```
从页面中提取所有比赛
筛选条件：球队名称（模糊匹配）
结果：找到 N 个候选
```

### 步骤 3：时间筛选（如有）

```
如果提供了完整时间（YYYY-MM-DD HH:MM）
→ 优先匹配时间相近的比赛
→ 时间差异小的排名靠前
```

### 步骤 4：综合评分

```
对每个候选：
├─ 球队匹配（必要）：100分
├─ 主队完全匹配：+30分
├─ 客队完全匹配：+30分
└─ 联赛匹配（辅助）：+20分

选择得分最高的候选
```

### 步骤 5：验证阈值

```
if score >= 100:
    return 匹配成功
else:
    return 未找到匹配
```


**匹配过程：**

```
1. 访问页面：shuju-20251102.shtml ✅
2. 查找候选：找到 "美洲 vs 莱昂" ✅
3. 时间验证：11:10 完全匹配 ✅
4. 球队匹配：
   - "墨西哥美洲" 模糊匹配 "美洲" ✅ (100分)
   - "莱昂" 完全匹配 "莱昂" ✅ (+30分)
5. 联赛验证：
   - "墨西联" → "墨超" 匹配 ✅ (+20分)
6. 总分：150分
```

**结果：** ✅ 成功匹配 fid=123456

## 🆚 与旧版对比

### 旧版策略（球队优先）

```
问题：
❌ 球队名称必须完全匹配
❌ 联赛不匹配会大幅减分
❌ 忽略了时间这个最可靠的因素

结果：
墨西哥美洲 vs 美洲 → 匹配失败
```

### 新版策略（时间优先）

```
优势：
✅ 时间作为主要筛选条件
✅ 球队名称模糊匹配（支持翻译差异）
✅ 联赛仅作辅助（不强制匹配）

结果：
墨西哥美洲 vs 美洲 → 匹配成功（通过模糊匹配）
```

## 🎯 核心优势

### 1. 时间最可靠

```
比赛时间通常精确到分钟
各网站使用统一的UTC或固定时区
很少出现差异
```

### 2. 容忍翻译差异

```
球队：墨西哥美洲 ≈ 美洲 ✅
联赛：墨西联 ≈ 墨超 ✅
```

### 3. 多候选智能选择

```
同日多场比赛 → 通过时间筛选
同联赛多场 → 通过球队匹配
翻译不同 → 通过模糊匹配
```
