## 🔍 扫描到 0 场问题排查

### 现象

```
✅ 找到 16 场有盘口的比赛（原始：129 场）
各天扫描结果: 0 场
```

### 可能原因

1. **日期匹配问题**

   - 盘口数据的日期格式与比赛列表不一致
   - 时区差异导致日期错位

2. **盘口数据源问题**

   - 500.com 当天无盘口数据
   - 盘口接口返回空数据

3. **名称匹配失败**
   - 队名清洗后无法匹配
   - 时间格式不一致

### 排查步骤

#### 1. 查看详细日志

重启服务后查看后端日志：

```bash
python app.py
```

关注这些日志：

```
🔍 正在扫描 2025-11-15 (1/21)
  ✅ 获取到 X 场原始比赛
  📊 必发比赛Map大小: X
  📊 盘口数据条数: X
  🎯 盘口过滤后: X 场
```

#### 2. 临时关闭过滤

在采集时**取消勾选"仅显示有盘口"**：

- 这样可以看到是否能获取到原始数据
- 如果能获取，说明是盘口匹配问题
- 如果不能，说明是数据源问题

#### 3. 检查特定日期

手动查询特定日期：

```bash
curl "http://localhost:5001/api/matches/finished?date=2025-11-15"
```

### 解决方案

**方案 A：使用无过滤模式**

```
1. 取消勾选"仅显示有盘口"
2. 开始采集
3. 采集完成后在回测时再过滤
```

**方案 B：调整日期范围**

```
1. 缩小日期范围（如只选最近3天）
2. 观察是否能正常采集
3. 逐步扩大范围
```

**方案 C：清除缓存重试**

```bash
# 删除缓存文件
rm -rf d:\MSM\Cursor\football\data\*

# 重启服务
python app.py
```

## 📱 跨设备会话继承

### 问题

不同设备登录后无法继承采集进度，每次都重新开始。

### 原因

会话数据存储在本地文件系统：

```
d:\MSM\Cursor\football\progress\session_*.json
```

### 解决方案

#### 方案 1：手动同步会话（推荐）

1. **在原设备上**

   ```bash
   # 复制会话文件
   d:\MSM\Cursor\football\progress\
   ```

2. **传输到新设备**

   - 使用 U 盘/网盘
   - 或通过网络共享

3. **在新设备上**

   ```bash
   # 粘贴到相同位置
   d:\MSM\Cursor\football\progress\
   ```

4. **刷新页面**
   - 点击"📋 历史会话"
   - 选择需要继续的会话

#### 方案 2：API 查询会话

在新设备上查询会话 ID：

```bash
curl http://原设备IP:5001/api/progress/sessions
```

复制会话 ID 后在新设备恢复。

#### 方案 3：共享存储（高级）

将 progress 目录放在共享存储：

```python
# 修改app.py
progress_manager = ProgressManager(progress_dir="//NAS/shared/progress")
```

### 最佳实践

1. **记录会话 ID**

   - 每次采集开始后立即复制会话 ID
   - 保存到记事本/云笔记

2. **使用历史会话**

   - 定期查看"📋 历史会话"
   - 找到中断的会话继续

3. **备份进度文件**
   ```bash
   # 每天备份
   xcopy d:\MSM\Cursor\football\progress\*.json 备份目录\
   ```

## 🐛 常见问题

### Q1: 为什么有些日期扫描到 0 场？

**A:** 可能原因：

- 该日期没有完场比赛
- 盘口数据源无该日期的数据
- 网络问题导致获取失败

**建议**: 查看日志中的错误信息。

### Q2: 扫描很慢怎么办？

**A:** 优化方案：

- 减少扫描天数（分批采集）
- 取消"仅显示有盘口"过滤
- 检查网络连接

### Q3: 如何查看会话的详细信息？

**A:** 方法 1：

```bash
curl http://localhost:5001/api/progress/session/会话ID
```

方法 2：

```bash
# 直接查看文件
cat d:\MSM\Cursor\football\progress\session_会话ID.json
```

### Q4: 采集中断后如何恢复？

**A:**

1. 点击"📋 历史会话"
2. 找到 paused 状态的会话
3. 点击选择
4. 点击"恢复采集"

自动恢复服务也会每 5 分钟检测并尝试恢复。

Get-Content app.log -Wait -Tail 50
