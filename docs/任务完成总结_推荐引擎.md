## 💡 使用示例

### 完整流程示例

```python
import requests

# 1. 获取比赛列表
matches_response = requests.get("http://127.0.0.1:5001/api/bifaw/matches")
matches = matches_response.json()["matches"]

# 2. 选择一场比赛
match = matches[0]

# 3. 生成推荐
recommendation_response = requests.post(
    "http://127.0.0.1:5001/api/recommendation/generate",
    json={
        "match": {
            "home": match["home"],
            "away": match["away"],
            "league": match.get("league"),
            "kickoff": match.get("kickoff")
        },
        "detail_url": match["detail_url"],
        "format": "both"
    }
)

result = recommendation_response.json()

# 4. 显示推荐
print(result["vis_output"])  # 完整分析
print(result["telegram_message"])  # 简洁版

# 5. 判断是否下注
recommendation = result["recommendation"]
if recommendation["最终推荐"]["should_bet"]:
    print(f"✅ 推荐下注: {recommendation['最终推荐']['direction']}")
    print(f"盘口: {recommendation['最终推荐']['handicap_str']}")
    print(f"置信度: {recommendation['最终推荐']['confidence']:.1%}")
else:
    print(f"❌ 不推荐: {recommendation['最终推荐']['reason']}")
```

## 🔒 X1 核心逻辑保留

### 资金等级（完全遵循 X1 标准）

```python
L1: <50,000        SBRE权重: 1.00
L2: 50,000-150,000   SBRE权重: 0.85
L3: 150,000-700,000  SBRE权重: 0.65
L4: 700,000-1,500,000 SBRE权重: 0.35
L5: >1,500,000     SBRE权重: 0.15
```

### 评分等级

- **A 档**：低风险，置信度 ≥85%
- **B 档**：中低风险，置信度 70-85%
- **C 档**：中等风险，置信度 50-70%
- **D 档**：较高风险，不推荐

### 熔断机制

- **F-GATE**：数据链不完整
- **F-EVD**：证据不足
- **F-CONS**：一致性失败
- **F-CAP**：执行异常
