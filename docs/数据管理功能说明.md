# 📊 数据管理/分析功能说明

## 🎯 功能概述

**数据管理页面**提供了可视化的数据统计和管理功能，让你清晰地了解每天采集的数据情况。

## ✨ 核心功能

### 1. 总览统计卡片

显示四个关键指标：

- **总天数**: 已采集数据的天数
- **总文件数**: 总共采集了多少场比赛
- **总行数**: 所有 CSV 文件的总行数
- **总大小**: 数据占用的存储空间

### 2. 按日期统计表格

展示每天的采集情况：

| 日期       | 文件数 | 总行数 | 大小(MB) |
| ---------- | ------ | ------ | -------- |
| 2025-11-21 | 3      | 122    | 0.18     |
| 2025-11-20 | 7      | 1,606  | 2.28     |
| 2025-11-19 | 1      | 85     | 0.12     |

### 3. 点击展开详情

点击任意日期行，展开查看当天的所有比赛：

```
📁 2025-11-21 的比赛明细 (共 3 场)

┌─────────────────────────────────┐
│ 利物浦 vs 曼城 1900             │
│ 📊 128 行  💾 45.2 KB           │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ 巴萨 vs 皇马 2100               │
│ 📊 95 行   💾 32.1 KB           │
└─────────────────────────────────┘
```

## 🗂️ 数据组织结构

系统按照 **年/月/日** 的文件夹逻辑组织数据：

```
data/
  └─ 2025/
      └─ 11/
          ├─ 21/
          │   ├─ 比赛1.csv
          │   ├─ 比赛2.csv
          │   └─ 比赛3.csv
          ├─ 20/
          │   ├─ 比赛1.csv
          │   └─ 比赛2.csv
          └─ 19/
              └─ 比赛1.csv
```

## 📍 访问方式

### 方法 1: 从采集页面点击

采集页面右上角 → **📊 数据管理/分析** 按钮

### 方法 2: 直接访问

浏览器地址栏输入：

```
http://localhost:5001/data-manager
```

或服务器地址：

```
http://服务器IP:5001/data-manager
```

## 💡 使用场景

### 场景 1: 检查采集完整性

**需求**: 确认某个日期的数据是否采集完整

**操作**:

1. 打开数据管理页面
2. 找到对应日期
3. 查看文件数量是否符合预期
4. 点击展开查看具体比赛列表

### 场景 2: 数据清理

**需求**: 清理某些日期的旧数据

**操作**:

1. 查看各日期的数据量和大小
2. 确定需要清理的日期
3. 到文件系统中删除对应文件夹

### 场景 3: 统计分析

**需求**: 统计每天的采集量

**操作**:

1. 查看表格中的文件数列
2. 分析采集趋势
3. 优化采集策略

### 场景 4: 数据验证

**需求**: 验证某场比赛是否采集成功

**操作**:

1. 找到比赛日期
2. 点击展开详情
3. 在比赛列表中查找
4. 查看行数是否正常（通常>50 行）

## 📊 数据指标说明

### 文件数

- 每场比赛对应一个 CSV 文件
- 文件数 = 当天采集的比赛场次

### 总行数

- CSV 文件的数据行数（不含表头）
- 正常比赛通常有 50-200 行
- 行数过少可能表示数据不完整

### 大小

- 文件在磁盘上的占用空间
- 单位：MB（兆字节）
- 平均每场比赛约 30-60 KB

## ⚡ 性能优化

### 快速扫描

- 使用缓存机制
- 只在需要时扫描文件系统
- 支持增量更新

### 文件计数优化

- 行数统计采用快速读取方式
- 避免加载完整文件内容
- 大文件自动跳过详细分析

## 🛠️ 故障排查

### Q1: 显示"暂无数据"？

**可能原因**:

- data 目录为空
- 文件名格式不符合规范
- 权限问题

**解决方案**:

```bash
# 检查data目录
ls -lh data/

# 确认文件命名格式
# 正确: 2025-11-21_利物浦_vs_曼城_1900.csv
# 错误: match_123.csv
```

### Q2: 某些日期不显示？

**可能原因**:

- 文件名中日期格式错误
- 文件不是 CSV 格式

**解决方案**:

- 确保文件名包含 YYYY-MM-DD 格式的日期
- 文件扩展名必须是 .csv

### Q3: 数据不准确？

**解决方案**:

1. 点击"🔄 刷新数据"按钮
2. 重新扫描文件系统
3. 清除浏览器缓存

### Q4: 点击日期无反应？

**检查**:

1. 浏览器控制台是否有错误
2. 网络连接是否正常
3. 后端 API 是否正常运行

## 📝 最佳实践

### ✅ 推荐做法

1. **定期检查**

   - 每天查看一次数据统计
   - 确认采集是否正常

2. **及时清理**

   - 定期清理旧数据

3. **数据备份**
   - 重要数据定期备份
   - 避免意外丢失

### ⚠️ 注意事项

1. **不要手动修改文件名**

   - 保持原始命名格式
   - 避免破坏统计功能

   - 保持在 data 目录下
   - 按日期组织

3. **定期刷新数据**
   - 采集新数据后刷新页面
   - 确保显示最新统计
