## 🔍 根本原因

### 列名关键字不匹配

**我们查找的关键字：**

```python
if '赔率' in col or '价格' in col:
    odds_col = col
```

**实际的列名：**

```
主胜_欧赔
主胜_价位
和局_欧赔
和局_价位
客胜_欧赔
客胜_价位
```

**没有包含"赔率"或"价格"！** ❌

## ✅ 最终修复

### 扩展关键字列表

**修复前：**

```python
if '赔率' in col_str or '价格' in col_str:
    odds_col = col_str
```

**修复后：**

```python
if any(kw in col_str for kw in ['赔率', '价格', '欧赔', '价位', '赔']):
    if '成交量' not in col_str and '方式' not in col_str:
        if '主胜' in col_str:  # 优先主胜
            odds_col = col_str
        else:
            odds_col = col_str
```

### 关键改进

1. **扩展关键字**：

   - ✅ 赔率
   - ✅ 价格
   - ✅ **欧赔** ← 新增
   - ✅ **价位** ← 新增
   - ✅ **赔** ← 新增（通配）

2. **排除干扰列**：

   - ❌ 成交量
   - ❌ 挂买/挂卖
   - ❌ 方式

3. **优先级选择**：
   - 优先"主胜"列（更有代表性）
