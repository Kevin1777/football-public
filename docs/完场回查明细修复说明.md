# 完场回查明细修复说明

## 🐛 问题描述

完场回查的比赛在抓取明细时，解析结果显示：

- ❌ "未知时间 未知联赛 主队? vs 客队?"
- ❌ 元数据无法正确识别

**原因**：
完场比赛的明细页面 HTML 中可能缺少标准的元数据标签（如`div.teammsg`或完整的`<title>`），导致`_extract_title_from_html`函数无法提取比赛信息。

## ✅ 解决方案

### 修改 1：parse_bifa_html 接受 match 参数

**文件**：`parser/html_parser.py`

```python
# 修改前
def parse_bifa_html(html: str) -> Union[pd.DataFrame, str]:
    """解析必发指数网页中的标盘明细表格。"""
    page_title_meta = _extract_title_from_html(html)
    # ...

# 修改后
def parse_bifa_html(html: str, match: Optional[Dict[str, object]] = None) -> Union[pd.DataFrame, str]:
    """解析必发指数网页中的标盘明细表格。"""
    # 如果提供了match参数则优先使用
    if match:
        page_title_meta = {
            "league": match.get("league"),
            "datetime": match.get("kickoff"),
            "home": match.get("home"),
            "away": match.get("away")
        }
    else:
        page_title_meta = _extract_title_from_html(html)
    # ...
```

### 修改 2：调用处传入 match 参数

**文件**：`app.py`

```python
# Selenium方法
html = bifaw_client.fetch_match_detail_selenium(
    detail_url=detail_url,
    match=match_info if isinstance(match_info, dict) else None,
    detail_params=detail_params if isinstance(detail_params, dict) else None,
)
# 传入match_info以便解析器使用比赛元数据
parse_result = parse_bifa_html(html, match=match_info if isinstance(match_info, dict) else None)

# 备用requests方法
parse_result = parse_bifa_html(response.text, match=match_info if isinstance(match_info, dict) else None)
```
