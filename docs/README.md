# 历史：PDF 解析工具

基于 Flask 的 PDF 解析应用，用于从 PDF 文件中提取表格数据。

## 📁 项目结构

```
football/
├── app.py                 # Flask 应用入口
├── requirements.txt        # Python 依赖
├── parser/                # 解析模块
│   ├── __init__.py
│   └── pdf_parser.py      # PDF 解析核心逻辑
├── templates/             # HTML 模板
│   └── index.html         # 前端页面
└── uploads/               # 上传文件目录
```

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
python app.py
```

### 3. 访问应用

打开浏览器访问：`http://localhost:5001`

回测功能帮助验证投注策略的历史表现。查看详细文档了解如何使用。
