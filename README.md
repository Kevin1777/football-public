# Football Data Service

⚽ AI-powered football data collection and recommendation system

## Quick Start

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python app.py
```

Copy the example files before running the service. Keep real passwords, API
keys, Webhook URLs, cookies and databases only in local ignored files.

- `.env.example` → `.env`
- `config/config.example.json` → `config/config.json`
- `config/wecom_config.example.json` → `config/wecom_config.json`
